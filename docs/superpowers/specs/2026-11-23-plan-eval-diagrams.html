系统架构

选择一个 Agent 版本，勾选多个场景或全选场景库，一次运行所选场景的全部跑者快照。每份快照独立生成 Artifact，再评分。

运行器详图

各 worker 分别处理快照执行项。Execute 调用生成模型 API；Evaluate 的两路 judge 读取同一份 Artifact。

某位跑者的生成模型调用失败时，只跳过该快照的评分。Artifact 已保存后中断，接管者恢复尚未完成的检查。

实体与主要属性

EvaluationTask.scenarios 保存选中的场景及其提交时的配置。每份跑者快照对应一个 SnapshotExecution。

场景库中的评分标准可以继续编辑。排队中的 worker 和历史报告均读取本次任务保存的标准。
