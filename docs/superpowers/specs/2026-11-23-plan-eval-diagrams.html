系统架构

一个测评任务选择一个 Agent 版本和一份或多份跑者快照。每份快照独立生成 Artifact，再评分。

运行器详图

各 worker 分别处理快照执行项。Execute 调用生成模型 API；Evaluate 的两路 judge 读取同一份 Artifact。

某位跑者的生成模型调用失败时，只跳过该快照的评分。Artifact 已保存后中断，接管者恢复尚未完成的检查。

实体与主要属性

TestCase 保存测评场景。提交 EvaluationTask 时独立选择 RunnerSnapshot，每份数据分别产生执行记录和评分。

报告按 EvaluationTask 汇总 SnapshotExecution 和 CheckResult。生成失败的执行项也会显示，并保留失败原因。
