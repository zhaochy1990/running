## 2. 契约（= run-workout/v1 + 两个可选字段）

**不新建段 schema（弃 V2，2026-10-27 终审）**：L4 直出 v1 形态（blocks/steps/五值 step_kind/duration·target 判别联合/rest 条件全保留），v1 追加：

```
type?: "E"|"M"|"T"|"I"|"R"|"LR" | null    // 生成时声明的主刺激类型（配速意义因人而异，意图显式）
purpose?: string | null                    // 训练说明：练什么/为什么/本周位置——给用户+给 R0 复盘（意图基准）
```

day 不需要（v1 的 date 由 L4 给周内落位、L5 校验修复定最终日期）；km 不需要（totals 派生，校验用）。四条 LLM 路径（自建课/赛季课/周计划/L4）共用契约与 lenient 容错层。

### step_kind 语义（全管道教义，#808）

- `recovery` = 组间慢跑恢复：**open target**（无配速处方）、以恢复为目的的短慢跑
- `rest` = 不在跑：唯一写法=独立 rest step；`step.rest` 步后字段停止新生成（legacy 读侧兼容）
- **变速课慢段 ≠ recovery**：有配速处方的慢跑=训练内容=`work` 步+easy target。判别式=有配速处方的慢跑是 work@easy
- `work` 涵盖一切有配速处方的跑步主体（含 E 课主体，v1 惯例 "easy run body"）

### 判定表（确定性派生，读 V1 字段）

| 判定 | 规则 |
|---|---|
| 质量段 | `step_kind=work` 且 target 落质量谱（R 下限延伸 ~ M 上沿+10s/km）且 duration 折算 **≥30s 且 >100m**——100m strides 与 <30s 加速不占 Q |
| 有氧段 | work/warmup/cooldown 步且 target 在 E 带容差内或 open |
| Q 配额 | 含 ≥1 质量段的课数；LR 内嵌 work 尾段算一节；比赛课本身是一节质量课 |
| 合法性 | 谱内校验，**不要求单带归属**（教练 MP-10s 处方天然跨带）；带归类（中点）只作统计 |

### 校验集（validation，C1-C9）

C1 周量守恒 ±max(3km,3%)｜C2 长跑唯一合值（赛周 lr=null 豁免为 0 节）｜C3 Q 配额｜C4 训练日 ≤上限｜C5 配速谱内｜C6 note 语义（无质量步且无短加速步→null）｜C7 质量课热身/放松在场（比赛课豁免）｜C8 展开守恒（课里程=blocks 展开 Σ步距离）｜C9 E 课时长分层（间隔日 30-60min/普通日 60-90min）。一致性校验：声明 type 的带罩住主质量段（距离最长者 ±10s/km）；purpose 必填。

## 3. 九条内容规则（证据链=#796 评论）

1. **E 时长分层**：普通 E 日 60-90min、质量课间隔日 30-60min（8weeks.md 教练原话+E 家族原生下限 30min），里程=时长×E 带折算——不固定 km（不随水平缩放）。
2. **质量课多样性**：跨周结构不重复；强度谱覆盖 T/乳酸阈值长间歇（MP-10~20s 级）；不得全周同型。
3. **赛周激活性质量课**：赛前 2-3 天一节 M 配速触感+短组（形态参照 5-8km@MP+1k×3-5(快15s)+400m×3-5）；原生出处=维持原则之八「减量期保强度即可维持」。
4. **长距离形态谱轮换**：纯有氧/渐加速/纯 MP 段/变速(快+慢)×N/混合，不得全用 M 尾段一种。
5. **比赛配速锚定目标**：比赛课处方=goal_pace±小容差，风险写 purpose/note——内容层不得静默降级（§3.5 延伸）。

## 4. projectZones 能力递进投影（⑥，数据标定+回测）

```
projectZones(current_vdot, target_time_sec, distance_m, runway) → 每周六带
① target_vdot = vdotFromRace(distance, target_time)
② gap≤0 → 恒定当前（维持）
③ v0 = min(current_vdot, target_vdot − 2)              // 丹氏第14章原生式
④ 逐周：ideal=(target−v)/剩余周，cap=0.8/<45 · 0.5/45-52 · 0.25/≥52
   v += min(ideal, cap)                                 // 未撞帽=直线精确抵达；撞帽=贴帽凹线
⑤ 带换算：阈值配速反解（vdotFromThresholdPace 逆）× 校准管线同源带比例
⑥ 残差=target−终点（撞帽时）→ 风险声明「所需斜率 vs 群体分位」
```

**参数出处**：线性形状=生产数据 2586 窗口对（前后半无差异）；封顶=20 用户 p90 分档取整（<45: 0.82｜45-52: 0.49｜≥52: 0.22）；丹氏 +1/6 周=高档 p75-p90（被背书）。
**回测**（17 用户 1800 三元组点）：中位偏差 −0.08（无偏）；离散主要来自比赛日噪声与个体非线性——「计划=政策」的实证注脚，个体偏差归 R0/R2 复盘纠偏。已知偏差：45-52 档实际偏前置（中位 −1.37，记录待 R0 数据回头校）；≥52 轻微保守（安全侧）。
**封顶与规则⑤调和**：训练带照封顶曲线走（比赛周可未达目标带——丹氏 2Q「逼近不抵达」）；比赛课处方仍锚 goal_pace；残余差距=multi_cycle 风险的量化素材（chaoyi 例：需 0.9/周=高档 p90 的 4 倍）。
