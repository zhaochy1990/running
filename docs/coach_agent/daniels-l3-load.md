# L3 载荷层——详细设计

> 归属：[daniels.md 总览](./daniels.md) · 治理规则同总览（只录已拍板决定）。**状态：设计定稿 + 38 案例三档实测全绿（2026-10-26，短 5-9 周 21/21、中 10-16 周 12/12、长 22-26 周 8/8）；已实现（devops#793，`phasing/load/` 模块，fixture 回放 38/38）。**

## 1. 定位与零 LLM 定案

载荷层把阶段划分结果（L2：结构+体量带+块模式+taper 属性）翻译成**每周跑多少、多难、按什么节奏**，外加「到时候怎么调」的规则（政策面）。判断已全部住在 L2，本层在带内做构造。

**零 LLM 定案（实测论证）**：纯确定性展开器（R0-R5 起点 + 全局贪心 + 节奏/taper/LR/Q 规则）对三运动员 × 12 种跑道 38 案例全绿，分化完全继承自 L2 体量带（峰值 107.5/95/71、LR 峰 32/25、Q 2/1 各异）。迭代过程（0/11→38/38 共七轮修复）的每一处失败都是可枚举的机械问题（计数 bug/门校准/豁免缺失），**零判断力缺口**——「判断在 L2、构造在 L3」分层正确。

## 2. 构造算法（实测定稿）

### 2.1 起点与场景门：常态基线 R0-R5（21 用户两轮实测）

- **R0 数据准备**：周序列连续补零（没跑的周记 0，跳过零周会令断练期均值虚高数倍）；只计完成周（周一+7d ≤ as_of）
- **R1 无效周剔除**：比赛周、赛后 14 天内、taper 特征周（量<前 3 周均值 70% 且后续 21 天内有比赛）、断练周（<15km）
- **R2 基线取值**：有效周**中位数**（近 12 周有效周 ≥3 取之 → 不足扩 16/24 周 → 取 24 周内最优 2 周 → 全无回退近 4 完成周均值）
- **R3 新鲜度衰减**：距最后一个 ≥15km 实跑周超 4 周起每周 ×0.97，下限 ×0.65
- **R4 场景门（按序短路）**：无有效周→回退 avg4｜断练回归（avg4<15km 或连续断练 ≥2 周）→0.4×衰减基线、ACWR 不适用显式标记｜赛后（距赛 ≤21 天）→0.8×衰减基线两块回满｜能力衰减（基线过期但仍在跑）→0.85×｜正常→衰减基线
- **R5 硬安全门**：avg4≥15km 时起点 ≤1.3×avg4
- 产出字段 `habitual_week_km` 进 L1（体量带下限与块位起点共用）；孪生账号不影响逐账号计算（已知数据观察，不立任务）

### 2.2 周量主循环（全局贪心）

逐周前向构造，**ACWR 帽是唯一真约束**（构造用 1.28×滚动 4 周均值、门 1.3，留 2% 余量；构造层次级规则与它冲突时一律让路——实测教训：「建设周单调不降」修正与帽冲突已撤回，恢复期后爬坡缓是科学正确形态）：

- 每周目标 = 所在阶段体量带**中位**；实际 = min(目标, 1.28×滚动均值)，且能进带下限就进
- **recovery**：低量平（min(带 lo, 起点×0.7)）
- **foundation / early_quality / transition_quality**：按帽爬升进带
- **final_quality**：平台块——承前封顶带内持平；末段 taper 曲线削至赛周（缺省削减 40%，30-50% 带内）；赛周 = 比赛本身 + 激活（FM 10-15km MP，profile 参数化）
- **吸收周**：全局建设周计数每第 4 周 ×0.75（跨阶段不重置——相位内计数会在短阶段漏排）
- 块机制继承：3+1（或 2+1）、块间增量 +3~8%（贪心实现中即帽驱动的爬升）、吸收深度 -22~30%、疲劳警戒 -35%+（执行回路场景）

### 2.3 LR 曲线

起点=近期最长跑 → 峰值 = min(32, 峰值周×0.33, max(22, 近最长×1.25))；份额 ≤36%（**周量 <60km 放宽 42%**）；**LR 下限低量档：计划峰 <58km 时下限随峰值下调（≈峰×0.36）**——FM LR≥22 下限 vs 份额上限的教义张力首次量化落地；taper 期随量缩、赛周 null（比赛本身不算训练长跑）；recovery 小 LR。

### 2.4 质量负荷（Q 配额与家族）

recovery=0｜foundation：km≥60→1 否则 0｜其余建设阶段：km≥70→2 否则 1｜taper=1（保短质量触感）｜赛周=1（激活）。强度家族=canonical 直映射（含冬季 transition_quality 以 T 为主）；**质量里程预算=软目标+越界警告**（硬门只留 E 份额下限）；strides 副课标记（不算质量课）。

### 2.5 阶段目标决定块形状（L2 块模式指派的本体）

foundation=递进块（量主变量）｜early_quality=递进块 R 占位｜transition_quality=递进块增量放缓、质量负荷增长｜final_quality=**平台块**（量持平、M 负荷增长，丹尼尔斯全马经典形态；末块削减）｜recovery=低量块。

## 3. 产出物（五件）

1. **周骨架（默认轨迹）**——实测定型行结构：`{week, canonical, block, role: "progress"|"absorb"|"taper"|"race", km, lr, q}`；按常规场景物化，用户看到的计划主体；消费方=L4/scheduler/前端
2. **块结构标记**——3+1 循环边界与块角色；消费方=R2（块边界=校准挂点）
3. **回补策略（政策面）**——三场景规则集（常规=块位+增量／疲劳=重复块位／超量=放大步长受帽）+触发信号条件+降周深度；消费方=R2 直接读取
4. **力量指导 policy（阶段级）**——方向性规则（练什么能力、怎么练），实质课表在 weekly plan 生成
5. **边界检查结果 + 里程碑对齐**——§4 全门通过状态 + L2 出口里程碑落到周序号

## 4. 验收门（实测沉淀的六条规则）

1. **三硬门**：ACWR ≤1.3（唯一真约束）；单周尖峰 ≤4 周均值×1.5；**块对块 ≤+25%，但不跨 recovery 边界**（卸载回弹归 ACWR 管）且**豁免「跨阶段进更高带」段**（每周 ACWR 合规的爬坡是合法形态）
2. **带贴合**：建设周落带内，**爬坡期豁免**（低于 lo 但逐周递增，或被 ACWR 帽压制——两种合法形态）；taper/吸收周豁免。**带下限可达性（重要发现，两形态）**：伤退低起点、以及 **L2 布局本身（前置 recovery 长度）决定 lo 可达**——L2 门需补「lo 在该布局下 ACWR 可达」校验，L3 豁免兜底
3. **节奏**：建设周 ≥8 才要求 3+1 吸收周；短跑道/final-only 豁免
4. **LR**：峰值 22-34（低量档随峰值下调）；份额 ≤36%/42%；赛周 null；期内单调
5. **taper**：赛周 0.35-0.72×峰；taper 段单调降；削减 30-50%
6. **块内微阶梯**（0.97/1/1.03，纯实现质感项）：让块内三周呈微递进而非平台直排
