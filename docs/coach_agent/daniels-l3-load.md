# L3 载荷层——详细设计

> 归属：[daniels.md 总览](./daniels.md) · 治理规则同总览（只录已拍板决定）。起点规则（常态基线 R0-R6）与四维度细则**待拍板**，见文末。

## 1. 定位

载荷层把阶段划分结果翻译成块计划与周骨架：**每周跑多少、多难、按什么节奏**，外加「到时候怎么调」的规则。判断已全部住在 L2（结构、体量带、块模式），本层在带内做构造——块机制是算术与教义规则，不是判断题。

## 2. 块机制（载荷的基本单位）

### 2.1 块（block）

- 块 = 3+1（或 2+1）周期：3 个递进周 + 1 个吸收周（丹尼尔斯计划原生形态：三周质量+一周纯 E）
- 每块两个数：**块位**（这块练多大量）与**块间增量**（下一块比上一块 +3~8%）——块位/增量抽象与量化为本体系扩展
- 吸收周深度：计划内 -22~30%；疲劳警戒更深（-35%+，属执行回路场景）

### 2.2 「每周 ≤10%」规则退役

10.0% 与 10.5% 无实质差异；该规则从硬门降为块内阶梯的缺省系数。替换为三个有依据的硬门（Gabbett ACWR 框架，非丹尼尔斯原生）：

1. **急慢性比 ≤1.3**（本周实际量 / 近 4 周均值；即 PMC 已算的 ATL/CTL 口径，>1.5 高危）
2. **单周尖峰 ≤ 前 4 周均值 ×1.5**
3. **月度块对块 ≤ +20~25%**（4 周滚动总量环比）

### 2.3 回补规则（降周后下一块回到哪）

缺省（常规吸收周）：**块重启**——下一块 = 上一块各周 + 块增量。示例：100/105/110 → 吸收周 77 → 下一块 105/110/115（w5=105），**不是**回 110、更不是 77×1.1=85，也不是进度线续走 113。急慢性验算 105/98=1.07。

另两种场景由执行回路（R2）选择：疲劳触发→重复上一块块位；超量适应→放大步长（+8~10%）且受硬门约束。三场景判定是执行时决策（总览 §3.1）。

### 2.4 阶段目标决定块形状（L2 块模式指派的本体）

- foundation：递进块（量是主变量）
- early_quality：递进块，R 质量开始占位
- transition_quality：递进块但增量放缓，块内质量负荷增长
- final_quality：**平台块**——块位不涨、在峰值位持平，块间增长的是 M 配速长距离负荷（丹尼尔斯全马计划经典形态：量中段见顶持平，换内容不换量）；末块转削减（taper 属性，深度 30-50%）
- recovery：低量块

## 3. 产出物（五件）

1. **周骨架（默认轨迹）**——全程每周一行：`{week, phase, block_id, block_role(递进|吸收), km, lr_km, quality:{sessions, family(R|I|T|M|mixed), km_budget}, strides, special(race|activation_km), down}`。按常规场景物化，是用户看到的计划主体；消费方=L4 内容层、L5 scheduler、前端
2. **块结构标记**——每个 3+1 循环的边界周序号与块角色；消费方=R2 执行回路（块边界=校准挂点）
3. **回补策略（政策面）**——三场景规则集+触发信号条件+降周深度规则；消费方=R2 直接读取决策
4. **力量指导 policy（阶段级，2026-10-26 拍板）**——每阶段一条方向性规则（练什么能力、怎么练的方向），如 foundation「自重基础力量+伤防，每周 2 次短课」、final_quality「维持性短课，赛前 72h 停力量」；**实质课表在 weekly plan 生成**，本层不出具体动作组数
5. **边界检查结果 + 里程碑对齐**——三硬门+维度门通过状态（构造完自查，违规 clamp 重排）；L2 出口里程碑落到具体周序号，R2 照单检查

**质量里程预算 = 软目标（2026-10-26 拍板）**：教义份额（早期质量 ~8%、过渡 ~10-12%）做软目标+越界警告，硬门只留 E 份额下限（foundation ≥90% / transition ≥75-80% / final ≥70-75%）——避免与 Q 配额双重硬约束打架。

## 4. 季节性插入点（暂缓实施）

见总览 §3.4：峰值块避开盛夏、夏季月份块位下调、E 份额上调、冬季放大块量。生效前提=训练城市气候常态进 L1（静态表）+ 场地可用性字段（均待补）。
