# AI Coach

## 前置评估模块

> Goal: 生成用户画像

代码位置，src/training_profile

包括下面多个维度，
1. 用户基础档案：年龄、性别、身高体重、静息心率、最大心率
2. 当前能力：历史 PB、最近 3-6 个月周跑量、乳酸阈值心率、乳酸阈值配速、每周可训练天数、可用训练时段（早上 / 晚上）、力量训练是否有健身房（徒手vs器械）
3. 约束条件
    1. 伤病情况、旧伤位置
    2. 是否长距离只能周末跑
    3. 是否有拉伸、按摩放松等时间和习惯


## AI 训练计划生成

> 目标，生成训练计划

1. 周期选择
    1. 按比赛日期倒推，不确定比赛的时候可以选择大致时间，例如3月初，11月底等
    2. 自由周期，不瞄准比赛，单纯提高能力

## 训练计划UI模块，用户交互

### 计划日历

1. 周视图，
    1. 每一天标注：跑步课（区分质量课和长距离）/力量课/休息日
    2. 周总揽，本周计划跑量，本周已完成跑量，本周所属阶段，周跑量环比
2. 月视图，需求同周视图，可能需要一些视觉调整
3. 待办提醒，
    1. 小程序订阅消息（可选，作为配置选项，用户可以打开或者关闭通知），提醒用户今天有训练，然后提醒用户今天的训练内容和重点，用户可以跟教练聊一下今天的训练
    2. 质量课和长距离提前一天就给用户提醒，让用户做准备

## 执行跟踪

1. 自动匹配，手表同步进来一条跑步记录，系统自动识别当天的训练计划
2. 训练执行情况，
    1. 根据这几个维度判断，
        1. 训练量（距离）
        2. 训练强度（配速）包括平均配速 / 分段配速 vs 训练计划的目标配速
        3. 心率，时长等
        4. 有没有掉速，间歇有没有顶不住，有氧有没有心率漂移等
    2. 结果判定，
        1. 完美
        2. 达标
        3. 偏快 / 偏慢
        4. 未完成
3. 用户未完成训练，可以在Coach 对话里面主动询问用户，为什么没有完成
    1. 给简单的选择（太累，伤病，没时间，跑别的课程了，天气不好，家里有事，出差了等等）
    2. 用户的反馈有可能需要用来更新用户画像
4. 复盘
    1. 单节课复盘
        1. 本节课表现点评
        2. 哪里做得好，可以改进的地方
        3. 简短建议
    2. 周复盘
        1. 本周跑量
        2. 本周反馈，哪里跑的顶，哪里没练等
        3. 每周周日晚上，AI自动生成本周训练小结，用户周一打开小程序就能看到
    3. 周期复盘
        1. 当某一个周期结束之后，复盘这个周期做了什么，给出进步信号

### 自动调整计划
根据用户的训练状态自动调整训练计划

规则举例：
- 连续2周执行很差，跑不下来（不是不愿意跑），降跑量，插入恢复周等。
- T课连续轻松达标 -> 适度上调 T 配速，加训练强度
- 伤病或者恢复（RHR，HRV）信号，暂停高强度间歇，改成E跑+力量训练

调整需要生成新的训练计划，并告诉用户，请用户应用新计划


### 配套辅助功能

1. 力量训练库
2. 补给方案（长距离课）
3. 恢复监测（HRV，睡眠，RHR等数据）
4. 训练负荷监控
5. 用户自己可以和教练对话的方式去记录训练笔记，训练反馈
6. 多周期训练计划，历史归档

### 管理后台

1. 查看每个用户的训练计划，执行情况
2. 训练模版库，各种标准周期的训练模版
