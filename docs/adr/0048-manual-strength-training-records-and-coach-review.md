# ADR 0048: 手动力量训练记录的来源边界与 Coach 复盘

Status: accepted

手动力量训练记录保存运动员实际完成的动作、逐组负重、次数或秒数，以及训练备注。手表同步记录提供设备观测。同一时段可能出现两种来源，单凭时间重叠无法确定它们描述的是同一次训练。

## 决定

- 手动力量训练属于活动域，拥有稳定的记录 ID。同一次训练的多次保存和历史编辑更新该记录。手录与手表同步记录各自保存，分别展示并标明来源，首版暂缓重叠检测。
- 运动员可从手录详情确认删除本人记录。删除后该记录退出活动列表、月度统计及 Coach 训练取证。服务端删除训练内容，仅保留防止旧保存请求重新创建同一记录的摘要。
- 日常 Coach 问答按问题范围优先读取已保存的手动力量训练记录，缺少手录时读取对应范围内的手表记录。已有手录时，用户明确指定某条手表记录后，Coach 才引用那条记录的心率作为辅助信息，并标明手表来源。
- 从详情进入的复盘会话以该条已保存记录的 ID 为锚点。同一运动员再次从同一记录进入时续接原会话。Coach 按当前已认证的用户身份读取记录。

课表处方沿用 [ADR 0043](0043-workout-contract-unification.md)，手表活动详情与设备分段沿用 [ADR 0019](0019-go-activity-read-endpoints.md)。交互细节见[力量训练原型说明](../design/mini-program-strength-training/README.md)。
