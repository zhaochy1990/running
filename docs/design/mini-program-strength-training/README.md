# 微信小程序力量训练原型

打开[原型](preview.html)进入小程序「训练」页。原型按现有[本周训练](../../../src/wechat-miniprogram/pages/index/index.wxml)、[活动记录](../../../src/wechat-miniprogram/pages/activities/activities.wxml)和[底部导航](../../../src/wechat-miniprogram/custom-tab-bar/index.wxml)绘制，复用项目图标与浅色主题。

## 设计决定

- **课表力量训练采用 A · 逐组跟练。** 从「训练」点「跑者下肢力量」，进入[课表详情](preview.html?view=plan)并开始训练。每次聚焦当前组，可以修改实际次数或时长。确认后显示组间倒计时和下一组目标，可等待或跳过。提前结束会保留已记录的组。
- **自由力量训练从「训练」开始。** 在「本周训练」的今日安排下面点「自由力量训练」。可以一边练一边记，离开后从「继续自由力量训练」接着记。它是一条独立记录，与当天的课表分别保存。
- **保存后的自由力量训练在「记录」回看。** 保存后先看到本次明细，返回「活动记录」会定位到该条记录。也可以从底栏「记录」进入按月列表，点已保存的记录查看或编辑。

## 自由力量训练

打开[录入页](preview.html?view=manual)，也可以从原型中的「训练」页进入。开始记录时自动使用上海日期，续记或编辑已保存的记录时会沿用原日期。

页面标题显示在顶部导航。表单从可编辑的训练名称开始，名称输入用底部分隔线。

- 每行是一组，组号自动编号。负重默认留空，可写数字或文字。单位默认 kg，也可选 lb 或自重。选择自重后跳过负重输入，详情显示「自重」。选择 kg 或 lb 时，负重留空也可保存，详情只显示数量。新增组的数量默认是 0，输入时可直接替换，保存时需填写大于 0 的实际数量，可按个或秒填写，单位文字与下拉箭头留有间距。组内采用类似 [WeUI 输入框状态](https://weui.io/#form_input_status) 的轻分隔线，字段聚焦或校验失败时就地提示。「添加一组」用文字按钮，组的删除和复制按钮并排靠右，复制会把这一组插入下一行，已有组依次顺延。删除整个动作的按钮位于卡片右上方。
- 整次训练共用一处选填备注，位于动作列表下方，初始显示约四行，保存后在训练详情展示。退出录入页后可继续填写草稿。编辑历史记录时，退出未保存的修改会弹出确认。

## 原型边界与验证

原型可离线使用，训练和活动列表使用演示数据，草稿和手动记录保存在当前页面，刷新即重置。课表卡片的手表、更多和教练操作在这里用于还原入口周围的布局。[活动记录空态](preview.html?view=records&state=empty)可用于走查首次记录。真机运行和真实记录保存留待实现阶段验证。

本地 Chrome 验证了 320–1440 像素宽度中的首屏入口、表单布局、草稿续记、逐组录入与复制、三种负重单位和多行备注的保存与回看、上海日期自动记录、按月回看及编辑、逐组跟练完整 12 组和提前结束。
