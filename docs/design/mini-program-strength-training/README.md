# 微信小程序力量训练原型

在浏览器打开 [原型](preview.html)，从示例「跑者下肢力量」课表点「开始训练」。页面从本仓库读取插图，可离线使用。

## 体验流程

1. **课表详情**展示动作清单、目标组数、每组次数或时长、组间休息。点动作可查看肌肉示意图和要点。
2. **训练中**默认带入当前组的课表目标。确认前可改实际完成量，记录后可以撤回。返回课表后能继续同一次练习。
3. **组间休息**从一组确认后开始，显示剩余时间并可手动跳过。逐组跟练预告下一组目标，休息结束后切到下一组。
4. **训练小结**展示已完成组数、已练动作、用时以及各组实际完成量。提前结束需确认，已记组保留，其余标为未记录。

训练中的视图可随时切换，保留同一份记录和休息状态。

| 方案 | 界面和操作 |
| --- | --- |
| [A · 逐组跟练](preview.html?variant=A) | 放大当前动作和实际完成量。完成后切到独立休息页，可跳过。默认方案。 |
| [B · 整页记录](preview.html?variant=B) | 所有组展开为表格，可跳到任意组填写。休息条固定在滚动列表上方，继续查看其他组时仍可见。 |
| [C · 动作面板](preview.html?variant=C) | 每次展开一个动作查看并记录各组。当前动作练完时，休息结束后展开下一个未完成的动作。 |

## 原型边界

入口仿照现有[课表详情](../../../src/wechat-miniprogram/pages/workout-detail/workout-detail.wxml)。样例为四个动作、十二组，复用仓库的[动作插图](../../../strength_illustrations/)。训练记录保存在当前页面内存，刷新会重置。此原型可用于浏览器走查，微信运行时和真实活动保存留待实现阶段验证。

## 手动记录

打开[手动记录原型](preview.html?view=manual)，也可以从示例课表或本周课表进入。录入的是自己已经完成的力量训练，可选择过往训练日期。日期默认按上海时区显示今天。

- **按动作**自由填写动作名称。不同重量或完成量分行录入，相同的几组可合写成一行。负重支持公斤、空杠、自重和未填重量，每组可以按次数或秒数记录。动作备注独立填写。
- **随手记**直接写下或粘贴一整段笔记，保存后原样展示正文和换行。
- 两种方式各自保留草稿。保存后从「已存记录」回看或编辑，也可用「填入示例」先体验一遍。草稿和已存记录都仅保存在当前页面，刷新即重置。

## 本地验证

在 Chrome 的 320、360、390、430、768 和 1440 像素宽度检查布局。验证了 12 组完整流程、提前结束和零组退出、按次数与按秒记录、休息自动结束和手动跳过、撤回后重新记录、三种方案切换和刷新重置。另复验了列表底部的休息条、倒计时结束时保留输入光标、弹层关闭后的焦点、非法数值提示，以及动作面板自动进入下一个动作。无横向溢出、浏览器脚本错误或 HTTP(S) 请求。

手动记录另在 Chrome 的 320–1440 像素宽度验证了多重量录入、组数合写、按秒记录、非法数值提示、草稿切换、原文换行保存、历史查看与编辑，以及上海日期默认值。
