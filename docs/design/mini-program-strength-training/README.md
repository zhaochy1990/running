# 微信小程序力量训练原型

**录入设计已定稿（2026-11-26）**

打开[原型](preview.html)进入小程序「训练」页。原型按现有[本周训练](../../../src/wechat-miniprogram/pages/index/index.wxml)、[活动记录](../../../src/wechat-miniprogram/pages/activities/activities.wxml)和[底部导航](../../../src/wechat-miniprogram/custom-tab-bar/index.wxml)绘制，复用项目图标与浅色主题。

## 设计决定

- **课表力量训练采用 A · 逐组跟练。** 从「训练」点「跑者下肢力量」，进入[课表详情](preview.html?view=plan)并开始训练。每次聚焦当前组，可以修改实际次数或时长。确认后显示组间倒计时和下一组目标，可等待或跳过。提前结束会保留已记录的组。
- **自由力量训练从「训练」开始。** 在「本周训练」的今日安排下面点「自由力量训练」。点「保存记录」会留在录入页并提示「已保存」，可继续加组或加动作，再保存时更新同一条记录。它是一条独立记录，与当天的课表分别保存。
- **保存后的自由力量训练在「记录」回看。** 从底栏「记录」进入按月列表，点已保存的记录查看或编辑。编辑时也在原地保存，返回即可查看详情。如果这条记录还有未保存的草稿，点编辑时会提示继续记录或放弃草稿后编辑已保存内容。

## 自由力量训练

打开[录入页](preview.html?view=manual)，也可以从原型中的「训练」页进入。开始时间取首次进入自由力量训练，结束时间取这次训练最后一次成功保存。历史编辑沿用原来的起止时间。日期按上海时区归到开始当天。

页面标题显示在顶部导航。训练名称默认按开始记录时的上海日期生成，格式为「YYYY-MM-DD 力量训练」，可以自行修改。训练名称和动作名称都使用上方标签与底部分隔线。聚焦时保留标签和已有内容，仅隐藏占位提示。空字段失焦后恢复占位提示。单位菜单支持键盘操作，校验失败在对应字段旁以文字提示。

- 每次展开一个动作。添加或点开其他动作时，前一个动作会折叠为名称与组数。点名称行可重新展开，已输入的内容会保留。若保存时发现折叠的动作有未填项，会自动展开并定位到对应字段。

- 每行是一组，组号自动编号。负重默认留空，可写数字或文字。单位默认 kg，也可选 lb 或自重。选择自重后跳过负重输入，详情显示「自重」。选择 kg 或 lb 时，负重留空也可保存，详情只显示数量。新增组的数量默认是 0，输入时可直接替换，保存时需填写大于 0 的实际数量，可按个或秒填写，单位文字与下拉箭头留有间距。组内采用类似 [WeUI 输入框状态](https://weui.io/#form_input_status) 的轻分隔线。「添加一组」用文字按钮，组的删除和复制按钮并排靠右，复制会把这一组插入下一行，已有组依次顺延。删除整个动作的按钮位于卡片右上方。
- 整次训练共用一处选填备注，位于动作列表下方，初始显示约四行，保存后在训练详情展示。返回训练页时若还有未保存的内容，可点「继续自由力量训练」续记。全部保存后返回，再次进入会开始下一次训练。编辑历史记录时，退出未保存的修改会弹出确认。

## 记录与 Coach 复盘

- 手动记录和手表同步记录分别保存、分别展示，并标明来源。首版暂缓时间重叠检测。
- 详情使用左上角返回。底部的「编辑记录」使用白色次要按钮，「和教练聊一聊」使用红色主按钮。
- 练完保存后，用户可以退出录入页，到[教练 Tab](preview.html?view=coach)直接提问。Coach 优先复盘问题所指范围内的手动记录，缺少手动记录时使用手表记录。已有手动记录时，只有用户明确指定某条手表记录，Coach 才引用那条记录的心率并标明来源。进入具体训练详情后点「和教练聊一聊」会带上这条记录，同一条再次进入沿用此前会话。来源与会话边界见 [ADR 0048](../../adr/0048-manual-strength-training-records-and-coach-review.md)。

## 原型边界与验证

原型可离线使用，训练和活动列表使用演示数据，草稿、手动记录及演示对话保存在当前页面，刷新即重置。教练原型按当前记录生成示例回复，直接提问时支持单个日期或最近一次。正式 Coach Agent 和真实记录保存留待实现阶段。课表卡片的手表、更多和教练操作在这里用于还原入口周围的布局。[活动记录空态](preview.html?view=records&state=empty)可用于走查首次记录。

本地 Chrome 验证了 320–1440 像素宽度下的录入和回看、动作切换与校验、组复制、原地保存、跨午夜续记及逐组跟练完整 12 组和提前结束。另验证了手动与手表来源分开展示、两处教练入口、手动优先与手表兜底、同条记录续聊及历史修改保留训练结束时间。
