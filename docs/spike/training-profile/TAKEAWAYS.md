# 画像POC：从未达标的统计摘要重做

## 第一轮结论撤回

用户明确指出：准确统计、引用和大量局限说明没有形成可用于训练计划的用户insights。此前将其称为“有依据的描述性画像”降低了目标；第一轮没有通过内容验收。代码测试、独立review和CI只验证了实现与数据处理的一部分，不能代替画像质量。

## 根因

1. 导出使用活动列表接口，所有laps为空，却没有补取已有的活动明细。模型缺少训练过程中表现变化的证据。
2. 模型输入以计数、总量和已有阈值为主，且限制自行比较；只要求最多几条“候选”。有用的跨记录推断被压缩成复述。
3. 画像正文反复罗列未知和否定说明，却没有要求每条回答“这个人有什么特点，计划因此会怎样不同”。
4. 把未发现规律解释为资料不足，没有先检验读取和分析是否充分。既有校准或记录本身也未被用于清晰判断个人优势与需要关注之处。

## 第二轮修正

保持独立TS包与本地文件范围；不接Go存储、数据库或训练计划。沿用固定历史窗口，使用既有只读DataProvider补齐分段并另存快照。新算法只做区块、条件匹配和跨记录对照，不重写个人基线。

新增证据支持近期实际承载与高量期的区别、长距离后程执行能力、条件接近的环境对照，以及单次测试与同期训练的一致性分析。匹配不根据结果正负选样本；全部候选和排除理由留在本地分析记录。

画像条目增加 `planningUse`，正文围绕“认识—依据—规划用途”。详细局限和未成立方向保留作审核材料，不占据正文。当前不存在证据的特点不填空壳。模型产出条目不等于质量验收通过；本轮继续逐条复核和独立review，最终需要用户判断是否贴近目标。

## 验收应看什么

- 是否有超出原始记录列表的新认识，并对本用户成立。
- 依据能否支持正文强度，是否检查反例、选择偏差及适用条件。
- 未来计划引用它时，会作出什么具体不同选择；事实、能力估计、观察关联不混用。
- 证据不足的方向是否被移出画像，而不是用长篇不确定说明填充。

正式支持门槛仍留给POC后的决策；自动任务、生产存储和消费接入依旧不属于本轮。

## 模型与审查约束补充

用户要求后续测试仅用DeepSeek Flash。已在生成入口强制校验，允许调整输出预算和推理强度，实际参数写入metrics。历史两次Pro输出不计入Flash效果。

审阅曾发现：把观察心率差当成可增加心率目标的额度、把单次补给推广为方案、以单日负荷比和HRV范围推导维持绿灯、将数值范围全部说成比某值快。这些均不作为合格认识。另修复天气材料引用缺失：既然模型可见共享对照备选，其原始依赖也必须完整保留。只增加推理预算不能替代这些内容核对。

## 自主Agent试验

用户认可四跑日结构、长距离刺激集中、温度线索等已有认识，进一步要求由Agent自主提出假设、调用工具计算、找反例并修订。旧版固定对照不再是生成入口，旧结果保留作事后对照而不进入模型起始提示。

新增假设账本与来源receipt，使支持、反证、修订过程能在本地回看；通用计算工具允许选择未预设的字段和方法。只做schema或过程完整性检查仍不能代替内容审查，尤其需要核验反证是否真正挑战假设、样本选择是否偏、规划用途是否越界。

首轮真实自主试验已完成：仅DeepSeek Flash，high／32768，约5分25秒，28个模型决策轮次、28次成功计算，提出9个假设、提交8条。Agent确实在反证后放弃了一项混杂的能力提升假设，也自行探索了旧版固定对照之外的方向。该轮使用修复前的Deep Agents harness；原始输出永久保留在私人目录，不因审阅而改写。

内容不能原样通过。独立复算发现数字抄错、按圈数而非距离切半、四舍五入后再分类、硬写窗口周数，以及已发现的反例未进入最终结论。另一类错误是把分类标签当成实际训练强度、把运动学相关当成技术处方、把排除一种解释当成证明另一种原因。这些问题不靠“有反证receipt”或更高token预算自动解决。

本轮另存明确标注的人工审阅副本：5个方向修订后可作为定性规划输入，2项只留辅助观察，1项因果结论删除。发现更多方向的目标已有进展，自动生成可直接信任的画像仍未验证；最终质量由用户审阅。私人报告保留原稿、逐项处置、复算代码、样本与错误，不把人工纠正算作Agent自主纠正。

运行报告用量约179万token，包含每轮重复上下文；未取得缓存细分与计费金额，不能当作唯一输入量或实际费用。相比一次综合生成，探索循环明显增加耗时和上下文用量。下一轮优先观察收口时是否忠实使用反证，以及能否减少重复上下文，不先扩大分析方向清单或设计完整支持分级。

源码review后的修复与这次实测分开记录：改用无隐式摘要的单Agent循环，来源依赖由宿主保守绑定整份快照，修复反证门禁的拼合漏洞，记录工具失败，提交时保留事实／本人陈述／已有估计／系统推断的类型轴。本轮增加离线回归验证；修复后的harness未另跑一轮模型，不能把首次实测指标归给修复版。
