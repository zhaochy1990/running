# 十维训练画像 POC

用户已确认的本轮范围：继续用独立TS包和私人本地文件，只用DeepSeek Flash；固定内容由代码计算，需要提取／探索的内容交专项子Agent，master统一复核。仍是throwaway试验，不接生产存储或训练计划。

## 内容模型

一级维度固定为：基础信息与训练经历、训练目标与优先级、训练时间与环境约束、当前运动能力、训练结构与承受情况、恢复能力与近期状态、伤病历史与当前限制、执行习惯与训练偏好、补给与比赛经验、个体训练反应规律。维度内属性开放，数据没有覆盖的维度不填猜测。

每条信息独立记录：

- `dimensionId`：十维归属；`nature`：事实、统计观察、估计、偏好、目标、限制、感受或关联。
- `sourceTypes`与来源版本：运动／健康记录、已有负荷／校准、本人原话或历史画像引用。
- `formation`：直接引用、固定代码、Agent原文提取、Agent探索；`computation`另外区分预定义算法、自编计算、无计算及旧版本方法。
- 生命周期、来源日期、适用范围、支持程度与规划用途。Agent写JS并不变成固定算法；代码执行也不保证推断成立。

明确偏好、目标、本人限制／感受必须有逐字原文。旧周复盘混有教练分析，不作为本人原话。行为频率不会自动转成偏好，未记录不会自动转成没有经历或没有伤病。当前目标／限制仍保留来源与时间，历史认识不覆盖最新约束。

## 执行

```text
固定快照 + 一个或多个已审阅历史文件
  → 复用固定统计、能力／负荷产物和现有对照方法
  → Flash master按来源覆盖派发专项子Agent（并发最多3）
      → 读取固定计算；需要时编写新检验；支持／反例／修订
  → master检查全部旧条目，独立复算关键结果，取舍新候选
  → 本地profile／dimensions／layered／coverage／analysis／metrics／trace
```

采用现有LangChain `createAgent`，通过工具调用独立子Agent，避免重新引入隐式摘要或隐藏模型调用。专项任务覆盖能力、恢复、陈述／习惯、补给／比赛、个体反应，按来源是否存在选派；不为代码已能完成的维度强开LLM任务。每个任务18个模型决策轮次，允许一次有具体反馈的重做；master最多24轮，整轮最多150个模型调用尝试、20分钟。所有模型实例在创建前强制校验Flash。

固定计算结果不由master重写；新推断要有支持及不同方法的反例记录，本人原文提取无需统计假设。这个门禁验证材料存在，不能代替内容质量审查。

## 旧认识维护

支持多个历史文件，避免不同轮次的相同局部ID冲突。来源已撤回／修订的条目屏蔽；其余每条都必须检查并明确retain、pending_review、update、merge或withdraw。缺一条即拒绝提交，不能用“本轮没再发现”当作删除原因。

update／merge／withdraw需要master计算记录；merge指向同维度同性质的保留条目。原支持程度与适用条件保留，待复核不伪装已重新证实。原始文件不修改，所有取舍留在新结果及trace中。

## 内容验收

检查十维归属与性质／来源／形成方式是否忠实，固定数值是否稳定、探索是否形成有用的新认识、反例是否影响主体结论，以及旧温度等认识是否得到明确处理。空维度单列覆盖报告，不在画像正文重复未知说明。原始输出与生成后人工复核材料分开，不能把人工纠正算作模型自主纠正。

实现依据：[LangChain官方子Agent工具编排](https://docs.langchain.com/oss/javascript/langchain/multi-agent/subagents)。

实测后的编排修复：普通工具校验错误写入journal并作为ToolMessage返回，允许模型自纠；临时探索成功后可以显式reuse绑定假设，不必重算。子任务修订沿用外部假设／计算账本，并收到剩余轮次提醒。禁用客户端隐式重试，成功与失败调用尝试均计数。本人原话交专项提取，不由固定统计猜语义维度。

## 生成后审稿与局部重跑

原稿质量审查发现：master在reason里写了复算数字，却无法修正子报告原文；独立复算自身也会用错分块或混入非跑步。因此仅固定代码保持不可改，新候选可用显式correction修订，必须附master成功验证receipt和实际来源引用，保留原始子报告与修订链。

新增固定校验复用原分段函数，验证真正累计距离首末区块、等距离半程、原始精度分类；时段/间隔统一使用canonical跑步与上海日。个人偏好仍不得从时段推断。

可通过`PROFILE_REVIEW_RUN=/absolute/private/completed-run`和`PROFILE_REVIEW_FEEDBACK=/absolute/private/review.md`只重跑master。要求同一用户、相同快照hash、全部专项报告已完成、来源版本仍有效，且重复传入原运行的全部历史画像参数（历史集或内容不同会在模型调用前拒绝）；恢复已保存的报告/计算并禁止再派研究任务。指标只记本次master调用，探索用量保留在源运行中，不合并冒充一次生成。早期精简analysis的完整来源从原始child_report日志恢复，后续analysis直接保存完整报告。

带人工审核反馈的Flash修订与原始自主输出分开保存。即使格式、来源引用与测试都通过，内容仍需逐条判断，不能宣称无人审阅可直接用于生产计划。
