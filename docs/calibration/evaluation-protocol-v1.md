## 样本、时间、分割

manifest 固定 schema、来源版本、内容 SHA-256、截至时刻、设备、场景、活动根 ID、片段和健康行。原轨迹/原话留受控位置，Git 只收合成脱敏 fixture 与摘要。每次报告包含 manifest hash、实际用于预测的 input hash、代码版本（CLI 显式必填）、协议 hash、实现身份和参数版本；不得查询可变线上数据。

用户内按事件时序冻结 train / validation / final_holdout（建议 60% / 20% / 20%，人数不足不机械切分）。分割是活动根级，活动、laps、片段及成绩派生物共用 root_activity_id；重复活动和跨集合根 ID 一律拒绝。相同用户 split 的事件边界不得倒序。最终留出完全不调参；训练参数仅用 train，validation 只用于选择已声明候选。

每个 prediction_as_of 只能读取 event_time <= cutoff 且 available_at <= cutoff 的输入。strict 还必须有不可变首次可得时间的证据引用；普通 updated_at、被覆盖的同步时间不算证明。活动的 available_at 指本次内容版本（含全部 laps/timeseries）最晚可得时间。健康数据也遵守同样门禁。无证明、仅事件日期的样本单独标 `event_date_retrospective`，不能进入 strict；未来才补录的成绩/标签在 report as_of 前不可得则不评分。同场留出活动及所有派生物从输入中整体排除。

## 独立参考标签

- `direct_60min`：独立计时、连续 3600 秒全力现场测试，暂停/恢复不能拼接；距离测量质量合格、明确全力协议及证据引用。实际测量速度/配速为直接参考；不借任何 Riegel 外推造真值。
- `race_prediction`：独立确认近全力、实际距离与完赛时间的比赛/测试。单独以完赛时间误差和相对误差评分；不能与直接60分钟标签混算。当前 T1 尚未实现独立跨时长预测接口，此类标签保留并报告 unsupported，不用同一公式同时造标签和预测。
- `constraint_only`：次极限训练、训练 HR 或用户自估。只检查同持续时长速度下界（容纳测量误差）、冲突和解释；不是精确真值，不能抬高标签数。

心率单独分层，禁止用配速派生 HR 再证明配速：

- `lab_lthr`：具日期、检测流程、仪器和实验室判读方法的乳酸阈心率报告；不同判读方法分层，不混为统一生理真值。
- `field_hr_proxy`：独立 30min 连续近全力现场测试，统一用末20min平均 HR；胸带、有效覆盖>=95%、缺口<=5s、无明显锁步/掉点，协议与环境可审计。只称现场 HR 代理量，不称生理 LTHR。
- `training_hr`：普通训练 HR、全力一小时平均 HR、按阈值配速附近片段反推 HR。只能验数据质量、协议一致性和循环依赖消除。

缺 lab_lthr 时不得宣称生理 LTHR 准确。T1 仅提供标签声明/门禁；HR 标量准确性 gate 尚未实现，报告必须保持未验收。

## 冻结数值门槛

所有确定性回归必须通过；旧个人回放内部配速容差 <=0.01 s/km。三版本固定配对交集评分并同时报告各自缺失；失败/少输出不能换更好分数。

最终 strict direct_60min 集：>=30 独立真实活动、>=10 用户，每人最多20%权重（按用户等权再对活动平均）；覆盖率>=90%，候选覆盖率不得低于两个基线，计算失败率<=1%。候选绝对误差中位数、P90 对 v3 均不得变差（容差仅1e-9数值误差），并对已实现的 segments_only 至少一项实质改善：中位数>=1 s/km 或 P90>=2 s/km。须同时报告有符号偏差、秒/km误差、N/用户数/独立活动数、缺失/失败率。

预声明分层：设备厂商、GPS异常/干净、暂停恢复/连续、质量课稀缺/充足，以及直接60分钟/其他距离；不得以赛后分层筛选得分。每个必要分层>=10独立活动、>=3用户，中位数退化<=1 s/km、P90退化<=2 s/km；不足则该分层 insufficient，不能宣称全量覆盖。当前真实设备/环境元数据缺失亦为覆盖缺口。

secondary race_prediction：>=60 独立活动、>=20用户；中位数/P90绝对相对完赛时间误差不劣 v3，且对 segments_only 至少一项改善>=0.5个百分点；设备/距离分层各>=10活动/3用户。只证明跨时长预测，不能替代直接阈值验收。

不确定性：固定 seed=983984、2000次按用户整组有放回 bootstrap，报告配对绝对误差中位数/P90差的百分位95%区间；v3配对差两项上限均<=0才允许统计非劣结论。区间描述的是误差差异估计，绝非个体阈值“95%置信区间”。合成样本不做准确性 bootstrap。

HR lab/field 分开：各>=30真实独立活动、>=10用户，绝对误差中位数<=3 bpm、P90<=6 bpm，且中位数/P90不劣v3；lab按方法、field按设备分层各>=10活动/3用户。无直接 HR 参考只验质量与循环依赖，不验收生理准确性。
