样本量、独立标签、严格历史可得时间、误差/覆盖/分层与统计门槛只控制候选上线。缺证据仍为 insufficient，候选继续离线/shadow，release_ready=false。生产active始终v3；不因提交、PR ready或合并代码自动切换模型，不自动重算生产历史。
