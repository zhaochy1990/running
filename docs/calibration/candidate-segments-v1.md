# T2 候选片段测量规则与回放（#985）

`segments_v1_v3_estimator` 是同一 Go calibration 域的离线实现，参数版本 `segments-v1-conservative-research`，离线快照版本4。`segments_only` 与 T2 的 `candidate` 共用它；T3–T5 只演进后者。生产入口仍调用冻结 v3，原版源码 hash 与 golden 不变。冻结协议的数值验收门槛没有修改。

## 测量约定

唯一新增公开纯函数是 `BuildCandidateSegments(history, durations)`。返回测量候选及逐活动诊断；这些是 measurement quality，**不是** maximal effort 证据。候选保留 Activity 供域内后继使用；`EstimateOffline`/Replay 只投影活动ID、真实窗口、速度与质量，不重复输出原始活动/轨迹。

- 时间统一使用记录的 elapsed 时间分母：有至少两个有限 TimestampS 时固定使用该时钟，否则固定使用 ElapsedS，不逐点混钟、不以样本下标补时间。时间缺测、重复/倒退、相邻间隔>10s切开；不会排序后拼接不同时间段。时间重启后在新段恢复。
- 每个距离锚点同时保存该点时间，距离差和 dt 永远同端点。相邻有效锚点速度上限8.5m/s；异常点不成为下一锚点。下降后若下一点回归旧轨道则拒绝该点；若下一点支持新的非负距离序列则建立新距离 epoch，不相减跨越重置。短缺失/拒绝点只在同 epoch、跨度<=10s的有效端点间线性插值；长缺失保持缺测。
- 速度只接受有限的 [0,8.5]m/s，零和低速均有效。时间积分使用相邻有效速度的梯形面积；窗口起点在采样间时按相同线性模型精确积分。距离使用同端点差；分母始终是完整窗口 elapsed，绝不除以“有效样本个数”或删除低速时间。
- 连续<=0.3m/s至少10s作为显式静止边界。有两个速度端点时优先据此判定；速度缺测时可用同 epoch 距离的静止增量。边界前后不拼接连续努力；不足10s的零速和走跑恢复保留完整分母。缺测不当成零速。
- 需要某一通道时间覆盖>=95%才可作为窗口速度来源。不足100%时记录缺测并降为low；缺失时间不重标度，已观测面积/完整elapsed是保守的部分观测值。距离优先，缺失时才使用速度积分并注明 fallback。两个通道都合格且相差>10%时记录两个值、取较慢口径并降为low，不能挑快值。
- 完整可比的活动距离/时间与 timeseries、同类型 lap stream 与 summary 做10%一致性检查；不同lap类型不相加。summary 的 elapsed 与记录时长不一致也降级。现有 watch adapter 可能将原始时钟统一成相同 elapsed 字段，无法从已丢失的信息证明自动暂停语义；冲突时不称连续全力。
- 仍保持旧的20min以上 CV<=0.12片段稳定性规则，但 CV 改为按已观测速度时间积分并包含有效零/低速；一、二阶矩都以已观测速度时间归一，缺测不当零。此归一只用于稳定性，窗口平均速度仍使用完整elapsed分母、覆盖不足仍独立降级。被拒绝窗口的原因计数、静止/缺口起止时刻、无法支持的请求时长均随诊断返回。
- 有记录的 timeseries 无法支持目标时长时，不以 laps/summary 绕过缺口或暂停。无 timeseries 时只允许实际活动时长与请求时长相差<=10%的 summary，保留实际时长、标记 `summary_only_continuity_unverified`，质量low。不从缺失样本自动补出连续 lap 努力；因此覆盖可能低于v3，须如实报告。

10s缺口/暂停、0.3m/s静止、95%覆盖、10%冲突都是**保守研究选择，尚未用独立训练数据校准**；不是概率或生理边界。8.5m/s上限、20min/0.12稳定性规则沿用旧测量选择。T1未声明新的数值冲突参数，本文件显式补充候选参数身份，不追称其为T1已校准规则。尚无独立准确性结论。

## 旧估计器对照

清洗后仍调用冻结的 `estimateThresholdSpeed`/速度—时长模型，保留已知一小时短路及其局限。非速度基线沿用v3。置信度取实际进入各时长桶的测量质量下限，避免低质量输入被旧估计器自动升级为high。HR仍用旧的配速条件规则并受测量质量上限限制；独立HR支持和循环依赖留给T5，不能把这里的HR称独立验证。

```sh
cd src/go
go test ./internal/compute/calibration ./internal/compute/calibrationsource ./internal/compute/watchmap ./cmd/stride
go test -race ./internal/compute/calibration ./internal/compute/calibrationsource ./internal/compute/watchmap
go run ./cmd/stride calibration replay --manifest /tmp/stride-983/private/fresh-manifest.json.gz --code-version <commit>
```
