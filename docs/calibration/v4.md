# V4：以 V3 已证明表现为基础的一小时能力估计

- 日期：2026-11-17。
- 状态：**待验证的算法设计**。本文没有对应的新算法实现或验证结果；参数是首轮研究初值。
- 算法身份：继续使用 V4，以 `algorithm_revision=v4-frontier-reserve-r1` 区分旧 V4；不另建 V5，不改冻结 V3。
- 目标：估计近期可比条件下，全力持续约一小时的平均速度 `v60`，以及该强度的模型心率。配速 `p60=1000/v60`，单位秒/km。
- 本轮交付：仅修改本文，供用户自行验证并反馈；不更新票、不改代码、不重算或切换生产。

## 1. 这次改变的核心

**保留 V3 每个 bucket 的可信最快表现，把它作为用户能力的下界；V4 估计这个下界之上还有多少未发挥能力。**

V3 的问题不是使用最好成绩，而是把某次训练的最好成绩过早当成了能力的最终答案。旧 V4 的问题是把“不能证明已经全力”变成“不能估计能力”。本设计同时纠正这两点：

1. 用户已经可靠完成的表现不能被新增先验、低心率或缺少全力标签否定。
2. 普通训练也参与估计；已核验全力测试增强校准，不作为输出的必要条件。
3. 在数据质量、时效和适用条件相同的前提下，V4 配速不得慢于有效 V3 基准。
4. V4 可以等于 V3。没有可解释的提升证据时，不加固定百分比制造进步。
5. 更快不等于更准。用户自估的 4′00″是待核查假设，不是拟合目标、先验中心或验收标签。

### 1.1 下界的准确含义

设用户在持续时间 `t` 内可靠完成平均速度 `v_obs(t)`，那么在这次活动的条件和能力状态下：

$$V_{max}(t)\ge v_{obs}(t).$$

这是**速度下界**，等价于同一时长最大能力的**配速上界**。它首先约束观测发生时的能力；迁移到“今天、参考条件”需要时效和条件假设。

- 可靠连续 60 分钟跑到 4′11″：同等条件下的一小时能力不能比 4′11″慢。
- 可靠连续 20 分钟跑到 3′50″：证明 20 分钟能力至少如此，不能直接断言一小时也能跑 3′50″。
- 可靠连续两小时跑到 4′11″：至少证明一小时能力不慢于该速度；进一步推算到约 4′00″需要耐力模型。
- “感觉还能再跑一小时”保留为用户陈述，不能生成不存在的两小时观测。

V3 的 bucket 原始表现与 V3 最终推算值必须分开。前者经过质量核查后是观测约束；后者有时来自短时外推或旧测量缺陷，只能作为经过审计的兼容基准。

### 1.2 方案取舍

| 方案 | 取舍 |
| --- | --- |
| 只删除旧 V4 的全力门槛 | 能改善空值，但没有保证结果尊重已证明表现，也没有解决余量估计 |
| 完全替换 V3，主要靠复杂生理模型和群体先验 | 可扩展，但增加不可辨识参数，容易让先验压过个人成绩 |
| **V3 基准＋表现包络约束＋有依据的余量估计** | 本文采用；保留已有能力，明确新增推断的贡献，可逐层消融验证 |

首轮不引入完整生理模拟、MCMC 或自由度很高的日级能力状态模型。先验证约束、时长外推和心率反馈是否提供增益。

## 3. 输入、测量与可比性

### 3.1 保留真实时间与来源

每条候选至少保留：活动根 ID、数据修订、上海活动日、实际起止时间、真实持续秒数、距离、平均速度、测量通道、完整时间覆盖、暂停/缺口、测量质量、条件标记、努力标签来源与可得时间。

同一次跑步的手表/平台副本先按来源根去重。没有可靠合并依据时标记身份不确定，不把副本当独立支持。

采用 [candidate-segments-v1](candidate-segments-v1.md) 的时钟、积分、距离重置和暂停规则。任何恢复都不能从平均速度的时间分母中删除；分段休息不能拼成连续全力表现。平均速度必须是距离/完整 elapsed 或同时间轴的速度积分/完整 elapsed。

**速度变化大不等于成绩不成立。** 旧的长片段 `CV<=0.12` 在新 V4 中只决定能否作为稳定训练/HR 拟合样本，不能单独删除一个测量完整、没有中断的真实连续成绩。间歇课如果整整一小时连续运动，保留包含所有慢恢复的整小时平均表现；若有需切段的静止/记录缺口，则不能跨段构造连续成绩。这是对旧片段筛选规则的一项明确调整。

### 3.2 三类证据角色

| 角色 | 准入与用途 |
| --- | --- |
| `trusted_bound` | 完整连续测量，来源与通道无未解决冲突，测量质量至少 medium，条件可比；可以形成硬约束，不要求全力标签 |
| `model_observation` | 有合法速度/时长，但覆盖、连续性或条件不能充分核实；可作宽误差估计，不能称已证明的当前下界 |
| `excluded` | 非有限数、时钟错误、已识别异常、无法解释的通道矛盾等；不参与求解，保留拒绝原因 |

沿用清洗器质量判定，但明确增加：`trusted_bound` 要求完整时间覆盖；部分积分结果即使数值合法，也不能借 high/medium 标签绕过该条件。默认不将 summary-only 认定为可信连续下界。

参考场景为用户近期可比的室外道路跑条件，不承诺已校正到统一温度。已知明显助力下坡、持续顺风、设备偏差或跑台标定差异的数据分别建组，不直接约束普通道路能力。无可靠环境信息时允许作为 `model_observation`；不能仅因“缺天气”删除原本已核实可比的道路成绩。可比性判定、人工核实与排除理由进入输入清单，验证时不得为改善结果事后调整。

首轮不套未经验证的统一气温、坡度或风速换算公式。模型 HR 的参考条件是所选可比活动组的典型条件，日效应设为零；不能把不同环境下的 HR 差异全部解释为能力变化。

### 3.3 时效与候选池

- 保存近 180 天候选及诊断；当前约束和主拟合使用近 60 天，边界按上海活动日、含第 60 天。
- 61–180 天成绩保留为历史能力和敏感性分析，不永久锁住当前能力。
- 每个 bucket 保留各独立活动的最佳窗口，随后得到近期全局最快值。不能先只留 180 天单一 PB，再发现它陈旧就丢掉所有近期候选。
- bucket 仅用于检索和分组。所有公式使用候选**真实持续时间**，不把 55 分钟重标成 60 分钟。
- 主配速拟合池：每个 bucket **先分证据层**。有 `trusted_bound` 时，只在这一层选最近 60 天最快的至多 3 个独立日，且速度至少达到这一层最快值的 97%；没有可信候选的 bucket 才在 `model_observation` 中按同样规则选取，并使用至少 low 的误差尺度。每活动每 bucket 只留一个窗口。弱质量的偏快 summary 不能定义可信层的筛选门槛或挤掉可信记录。已核验、测量可信且条件可比的全力参考另行保留，用于拟合及冲突诊断。
- 所有可信近期表现都参与约束检查，即使不在主拟合池。HR 可使用更多可比普通训练，但遵循第 6 节质量与日预算。

60 天、top-3 和 97% 是待验证的首轮选择，不是生理常数。选前沿池是为了避免大量慢训练把能力曲线拖低；它也可能遗漏有用信息，须做消融。

这里可进入拟合的全力表现只能是截止时已知、且不属于本次评分目标的历史输入。独立验证目标及其同根副本、结果标签和之后才知道的协议元数据不得进入候选池、下界、HRmax/RHR 输入或参数选择；不能一边用某场成绩约束模型，一边再用同一成绩证明预测准确。

## 4. 先建立 V3 基准与不能越过的下界

### 4.1 三个对照值，不混为一谈

对同一个 as-of 和输入清单计算或记录：

1. `B_raw`：冻结原版 V3 的阈值速度。
2. `B_repaired`：已有 `segments_only` 的输出，保持该对照自身规则，解释仅修复测量后发生了什么。
3. `B_eligible`：将第 3 节准入的近期可信标准 7 个 bucket，交给冻结 V3 的**配速聚合规则**得到的值。它是新 V4 的兼容基准，不冒称原版 V3 输出。

`B_eligible` 仍可能是模型投影，因此称“兼容基准”，不称“直接测得的一小时下界”。若聚合器没有足够候选而返回空，不阻止第 5 节利用单个短时观测给低支持估计。

有有效 `B_eligible` 时要求：

$$v_{60,V4}\ge B_{eligible},\qquad p_{60,V4}\le1000/B_{eligible}.$$

这是一条明确的产品兼容约束，不是宣称 V3 投影永远正确。V3 既不作为速度上限，也不在统计目标中再算一份独立观测。

### 4.2 原始表现形成曲线约束

使用与 V3 相近的速度—时长形式，首轮适用域为 180–7200 秒：

$$V(t;a,k)=\exp(a)\left(\frac{t}{3600}\right)^{-k},\quad v_{60}=\exp(a),\quad k\in[0.02,0.10].$$

对于域内可信观测 `i`，令 `x_i=log(t_i/3600)`、`y_i=log(v_i)`：

$$a-kx_i\ge y_i.$$

特别地，`t_i=3600` 时直接得到 `a>=log(v_i)`。短时 bucket 只在自身时长约束曲线；它对 `v60` 的影响依赖 `k` 和曲线形式，必须标注 `model_projected_bound`。

对于 `t_i>7200` 的连续长跑，不把完整活动裁成另一个 7200 秒测量，也不继续无界外推同一幂律。先使用非增能力曲线的必要条件：

$$V(7200)\ge v_i\quad\Rightarrow\quad a\ge y_i+k\log2.$$

这里 `V(7200)>=v_i` 是单调包络约束，`k log2` 是模型带来的小时换算。另行报告不依赖 `k` 的直接关系 `v60>=v_i`。超过两小时的原始时长完整保留，不能虚称精确识别了长时疲劳曲线。

合并后，给定 `k` 的可行下界为：

$$A_{floor}(k)=\max\left(\log B_{eligible},\ \max_{i\in trusted}\{y_i+k\log(\min(t_i,7200)/3600)\}\right).$$

不存在的项省略；全部不存在时不人为填零速下界。`min(t_i,7200)` 仅是上述长时包络的代数表达，不改变原始候选时长。

**中心解必须满足 `a>=A_floor(k)`。** 不能用有限惩罚权重替代，使先验或 HR 可以“付一点损失”就压穿已证明表现。测量不确定性在敏感性场景中显式改变输入并重算，不在主结果中统一扣掉 2% 来隐性放宽该承诺。

### 4.3 V4 比原版 V3 慢时，必须逐项解释

允许核查的原因只有具体证据变化，例如：

- `measurement_corrected`：修复删掉慢速时间、距离尖峰、暂停拼接或真实时长误标；附原窗口与修复后口径。
- `evidence_expired`：支撑旧值的活动离开当前窗口；附日期和新旧窗口。
- `conditions_not_comparable`：有明确地形、设备或条件反证；不能只写“模型认为不合适”。
- `capability_epoch_changed`：有用户确认的停训/伤病后能力阶段变化，见第 7 节。
- `v3_projection_conflict`：新的独立参考与 V3 的外推假设冲突。首轮只报告冲突，**不自动解除**兼容下界；由下一轮设计讨论决定如何修订。

缺少全力测试、HR 偏低、新模型更保守、研究先验更慢，都不是压低基准的合法理由。每次比较必须输出 `B_raw → B_repaired → B_eligible → v4` 及每一步的来源变化；无法解释的变慢视为设计/实现不符合本规范。

## 5. 在下界之上估计未发挥能力

### 5.1 潜在余量

域内观测模型：

$$y_i=a-kx_i-\delta_i+\epsilon_i,\qquad\delta_i\ge0.$$

`delta` 是对数速度余量，不是实际测得的“用力百分比”。例如 `delta=log(1.03)` 表示同持续时长的最大能力速度是该次观测的 1.03 倍，不表示心率、RPE 或主观努力提高 3%。

首轮用以下近似的正则化目标估计包络，而不另建庞大的潜变量采样器；Huber 与合并尺度并不是非负余量分布的严格边缘化：

$$L_P(a,k)=\sum_i w_i\,\rho_{1.5}\left(\frac{a-kx_i-y_i-\mu_{c_i}}{\sqrt{\sigma_{c_i}^2+\sigma_{measurement,i}^2}}\right).$$

`rho` 为 Huber 损失：`|r|<=1.5` 时 `r²/2`，否则 `1.5(|r|-0.75)`。可信观测另受硬下界约束；非可信观测允许残差包含测量误差，不能由残差反过来升级为可信表现。

这项损失表达“不要在没有依据时把能力推得无限高”的**余量先验**，不是把所有训练当成全力测试。`t>7200` 的记录仅进长时约束及适合的 HR 数据，不套此精确时长损失。

| 有来源的努力类别 | `mu_delta` 初值 | `sigma_delta` 初值 | 解释 |
| --- | --- | --- | --- |
| 核验的持续全力表现 | 0 | 0.015 | 更接近包络；比赛名称本身不够 |
| 可能全力、仍有不确定性 | 0 | 0.05 | 不自动给予固定提升 |
| 普通训练，努力未知 | 0 | 0.12 | 默认不强加余量，允许更大上方空间 |
| 明确连续稳态、报告尚有余力 | `log(1.03)` | 0.08 | 弱研究先验，不能取代真实持续时长 |
| 明确轻松跑 | `log(1.08)` | 0.15 | 宽研究先验，不把每次轻松跑都强制加速 8% |

训练计划名称不等于实际完成努力。用户原始反馈可帮助分类，但“我的阈值应该是 4′00″”不进入分类或余量数值。分类有冲突时用 `unknown`。缺反馈不阻止估计。

测量误差初值在对数速度域取 high=0.01、medium=0.025、low=0.06。它们是损失尺度，不是设备经过校准的误差率；low 不产生硬下界。

### 5.2 权重、耐力指数与解

对主配速拟合池，在同一天内按活动根均分、同一根内按入选窗口均分。设入选独立日数为 D，日权重定义为：

$$W_j=D\frac{2^{-age_j/30}}{\sum_{d\in selected\ days}2^{-age_d/30}}.$$

每条观测的 `w_i` 是该日 W_j 经上述根/窗口均分后的份额。这样所有证据一起变老、但没有进出窗口或修订时，权重不变，不会因整体衰减改变相对先验强度。副本或重叠窗口不能增加独立活动/日计数。加入完全不入选的慢训练不得改变这些权重。

耐力正则项：

$$L_k=\frac12\left(\frac{k-0.06}{0.02}\right)^2.$$

`0.06` 和 `[0.02,0.10]` 承接现有模型的研究范围，不代表已经测得用户个人耐力。只有普通训练时，耐力与努力余量不可充分区分；允许模型求出工作值，但输出 `k_support=prior_dominated`，不能宣称拟合精确识别。

无 HR 反馈时解：

$$(\hat a,\hat k)=\arg\min_{a\ge A_{floor}(k),\,0.02\le k\le0.10}\{L_P+L_k\}.$$

如果只有一条可信 60 分钟普通训练、没有额外余量证据，中心可落在该速度上；这是有效的保守估计，不是空值。只有短时或低质量普通训练也可用声明的 `k`/余量先验形成低支持估计，并明确较大的外推依赖。

只有超过两小时的可信记录时，L_P 可能为空：配速单独分支选择 k=0.06，并在满足所有约束的解中取最小 a，方法标注 `bound_fallback`，不让求解器在平坦目标上任取一个快值；若有有效 HR，仍可进入第 6 节的联合求解。只有超过两小时的弱质量合法记录、既无域内观测也无可信下界时，使用 `long_training_fallback`：固定 k=0.06，以各独立日最好的完整活动平均速度为宽位置先验，最小化 `sum_j W_j*Huber((a-log(v_j))/0.15)`。这只是“以已录制长跑均速给保守小时估计”的退化方法，标记 `prior_dominated`，不把活动重标为两小时或一小时实测。该路径不启用 HR→配速反馈；HR 可在固定配速处估计。短于 180 秒且没有任何域内/长时资料属于 `no_applicable_duration`，不伪装成缺全力标签。

### 5.3 防止循环增益

每次按明确 as-of 对原始证据批量计算，不执行“上次 V4 × (1+余量)”；当前 V3 基准只约束可行域，不作为额外似然。旧 V4 快照不重新作为个人能力观测。这样不会每天运行一次就又快一点，也不会因重复存储后验而增加确信程度。

## 6. 心率：帮助估计余量，也输出明确语义的心率估计

### 6.1 目标与输入

本文的 `threshold_hr` 指**估计一小时速度、参考条件下的模型稳态 HR**，记为 `H60`。它不等于一小时比赛平均 HR，不包含整小时热漂移，也不冒称实验室乳酸阈值。现场协议 HR、实验室 LTHR 保留各自独立来源和目标定义，不能直接混平均。

使用普通训练真实配对的速度/HR 时间序列。检查尖峰、掉点、时钟、疑似锁步；光电 HR 可用但误差更宽，不要求胸带或全力协议。优先使用连续至少 8 分钟、速度可用且条件可比的段落；保留其中的速度变化以拟合滞后，缺口切段，不填造逐秒 HR。

### 6.2 有有效 RHR/HRmax 时的联合模型

设 `R` 是已有 RHR 基线，`M` 是已有 HRmax 估计，`M>R`。使用：

$$H_{steady}(v,j,s)=R+(M-R)\,\operatorname{sigmoid}\left(\eta+\beta(\log v-a)+u_j+d_j s\right).$$

- `sigmoid(z)=1/(1+exp(-z))`。
- `eta` 决定参考条件下 `v=v60` 的心率储备比例 `q60=sigmoid(eta)`。
- `beta>0` 保证同条件下速度升高时 HR 不下降。
- `u_j` 是活动日偏移；`d_j` 是日内缓慢漂移，`s` 为该连续段开始后的小时数。
- 参考输出设置 `u=d=0`，因此 `H60=R+(M-R)sigmoid(eta)`。

真实 HR 存在滞后，采用一阶响应：

$$\frac{dH}{dt}=\frac{H_{steady}-H}{\tau}.$$

对相邻采样间隔 `Delta_t`，采用左端速度及该时刻漂移项：

$$\hat H_n=H_{steady,n-1}+(\hat H_{n-1}-H_{steady,n-1})e^{-\Delta_t/\tau}.$$

每个连续段以第一条有效 HR 初始化，该点不计残差；缺口大于 10 秒重新分段。速度非正或超出有效跑步域的区间不计算 `log(v)`，作为分段边界，不能用极小正数填补。活动根内的重叠 HR 段只用一份原始时间片。

研究初值与边界：

| 参数 | 中心与正则尺度 | 允许域 |
| --- | --- | --- |
| `eta` | `logit(0.85)`，标准差 0.6 | `q60` 在 `[0.65,0.98]` |
| `log(beta)` | `log(3)`，标准差 0.5 | `beta` 在 `[1,8]` |
| `log(tau)` | `log(60s)`，标准差 0.5 | 15–180 秒 |
| `u_j` | 0，标准差 0.25 | `[-0.75,0.75]` |
| `d_j` | 0，标准差 0.15/小时 | `[-0.3,0.5]`/小时 |

各正则项均为 `0.5*((参数-中心)/尺度)^2`，对数参数在对数域计算。日效应施加按有效时长加权的 `sum(w_j*u_j)=0` 约束，定义参考日；它并不证明天气影响已经被消除。`u/d` 的正则对日求平均，避免天数越多就凭空增强总体参数先验。

**0.85 不是已验证的个人阈值比例。** 它只是宽研究先验，必须做第 8 节敏感性分析。若 `M` 低于质量核实后的近期 HR，报告 `hrmax_input_conflict`，暂停该归一化模型，转入 6.4；不能硬截观测以维持假设。

### 6.3 HR 必须有真实反馈，但不能冲破成绩下界

HR 损失：

$$L_H=\sum_j W_j\,\operatorname{TimeMean}_{n\in j}\rho_{1.5}\left(\frac{H_n-\hat H_n}{\sigma_{H,n}}\right).$$

每一天先按真实覆盖时间求平均，然后对 HR 入选的独立日单独按第 5.2 节归一年龄权重；不能把上千个秒级点当上千场独立试验。胸带误差尺度初值 3 bpm、光电/未知传感器 6 bpm；都是待验证的研究尺度。配速和 HR 各自的独立日数及损失总量必须输出，便于核查 HR 日数很多时是否过度主导。

联合目标为：

$$\min_{a\ge A_{floor}(k)}\left\{L_P+L_k+\lambda_H L_H+L_{HR\ priors}\right\},\qquad\lambda_H=0.5.$$

在固定其他参数时，同速度下更低的可信 HR 可以支持更大的 `a`；跨日一致改善能提供更强依据。`a` 与 `eta` 存在尺度混淆，日效应也可能解释变化，因此这里的 HR→能力反馈仍依赖公开先验，不能声称从普通 HR 唯一识别了全力能力。

实现时必须保留 `lambda_H=0` 的对照；同配速、不同可信 HR 的反事实应能改变推断余量或其范围。如果模型总把差异全部吞进自由 HR 曲线，就没有实现有效反馈；如果单次低光电 HR 就大幅提升能力，说明正则或质量处理不合适。

速度窗口和其 HR 进入同一个联合目标，推算出的 `H60` 不再倒灌为新的独立参考。这里是正则化复合目标，不宣称各窗口/秒级残差统计独立。日/活动去重、范围评估与支持计数均使用真实证据根，而非项数。

### 6.4 缺失与退化路径

| 输入状况 | 配速与 HR 输出 |
| --- | --- |
| 有速度和可靠 HR，R/M 合法 | 联合估计；HR 标注 `model_estimated`，先验敏感时降为 `prior_dominated` |
| 有速度，无可用 HR，R/M 合法且有来源 | 配速走第 5 节；HR 可以输出 `R+(M-R)*0.85`，明确为 `prior_dominated`，范围来自先验情景，不能说来自个人训练拟合 |
| 有 HR，但 R/M 缺失或冲突 | 不阻断配速。对第 6.1 节可用段，在滞后/漂移诊断合格的末段，拟合正斜率 `H=c+b*log(v)`；以 Huber、日均分权重和 `b=60±30 bpm` 正则，限制 `b∈[10,150]`。在 `v60` 处预测 HR；此分支不反馈配速，标记尺度不可辨识。只有一个速度层时固定 `b=60` 并标记 `prior_dominated`；超出已观测速度域超过 10% 时同样降级并扩大情景范围 |
| 完全无 HR，也无可用生理先验 | 配速仍可输出；HR `unavailable` 并解释无可用输入，不能填一个无来源常数 |

6.4 的回归段采用每个连续段最后 5 分钟，速度 CV<=0.12、HR 首尾各 1 分钟均值差绝对值<=5 bpm，至少 95% HR 覆盖；否则不作为稳态回归点。使用完整时间加权均值，不能挑最高 HR。其 `b` 情景取 30/60/90 bpm，测量偏移取 ±6 bpm；数值越过有效观测 HR 范围的外推必须显式报告。

所有 HR 分支的主中心必须有限，并处于首轮沿用的候选 HR 计算域 `[80,230] bpm`；有合法 R/M 时还须 `R<H60<M`。这里是算法适用域，不是医学上的人体界限。域外或外推到不合法值时，不能钳到边界或只改成 low 后继续发布：有合法 R/M 的可退为带来源的 HR 先验中心，否则 HR 输出 `unavailable/hr_prediction_out_of_domain`，配速保留。范围触域时报告该侧未识别，不冒充完整双侧范围。

HR 不执行“越高越好”或“不低于 V3”的规则。速度的已完成下界逻辑不能套到 HR：同配速 HR 降低可能支持改善，阈值 HR 本身未必单调上升。

## 7. 近期变化、旧成绩和重复运行

首版采用 60 天当前窗、30 天权重半衰期及 180 天历史审计。可信近期成绩形成硬下界，因此衰减权重不能把中心压穿该成绩。近期更快的长时表现、跨时长支持和可比 HR 改善均可推动提升，不必等待刷新全部历史 PB。

- 相同输入修订、as-of、参数和模型修订，输出必须相同。
- 无新增有效证据时，不因每日任务运行而加速或收窄范围；可以改变“证据年龄/陈旧”状态。
- 只增加未入选的慢训练、且没有新增可用 HR 信息时，不降低原估计；不得把“最近练得慢”当成“最大能力变慢”。
- 全部当前支持过期时，保留旧中心作为 `stale` 展示或输出显式历史估计；不能把历史中心当作新鲜模型结果。若有足够近期模型观测但失去旧下界，可以产生较慢的新估计，必须报告 `evidence_expired`，并保留历史对照。
- 已确认的伤病/长期停训等造成能力阶段变化时，建立有生效日和来源的 `capability_epoch`，此前成绩仍是历史事实，但不约束新阶段。首轮不从少量慢训练自动推断新阶段。

本版没有解决全部能力下降检测问题。优先防止把未充分用力误判成下降；复杂状态模型只有在后续验证证明能改善跟踪且不破坏成绩约束时再引入。

## 8. 确定性求解、范围与失败处理

### 8.1 求解约定

无 HR 分支：`k` 在 `[0.02,0.10]` 上按 0.0005 网格枚举；固定 k 后对 a 的凸 Huber 目标作有界一维求解，并施加 `A_floor(k)`。数值搜索 `v60` 范围暂设 0.5–12 m/s；这是计算边界，不是人群生理上限。边界命中必须报告，不允许默默钳成成功结果。全部分支均遵守：目标并列误差在 `1e-8` 内时先取最小 a，再取最接近 0.06 的 k；包括只有约束、目标对 a 平坦的情况。

有 HR 分支：每个 k 从三个确定性 a 起点求解，分别为配速单独解、该速度的 1.03 倍、1.08 倍；HR 参数初值使用上表，约束和损失相同。采用有界确定性优化，最多 500 次迭代，相对目标变化小于 `1e-8` 且最大约束违反小于 `1e-8` 才算收敛；保留所有起点状态，选收敛解中目标最小者。并列误差在 `1e-8` 内时优先较小 a，再优先更接近 0.06 的 k。

这些规则保证可复算，不保证非凸联合目标达到全局最优。多个近似等价解差异明显时，扩大范围并报告 `identifiability_limited`，不能只展示最有利的解。

### 8.2 范围不是凭拟合残差得到的 95% CI

首轮报告 `model_sensitivity_range`，组合下列情景重算与目标剖面；不把该范围称为校准置信区间：

1. 固定 k 为 0.02/0.06/0.10，并与自由 k 结果比较。
2. 余量均值全部设 0、采用表中初值、将非全力均值乘 2；其尺度分别取原值的 1 倍、2 倍。
3. HR 反馈权重取 0/0.5/1；q60 先验中心取 0.80/0.85/0.90，beta 中心取 2/3/5。
4. 若 R/M 无已校准输入范围，R 取中心±3 bpm、M 取中心±5 bpm，明确这是研究情景；不得称测得的误差范围。
5. 按质量尺度对活动根的 log 速度施加同向 ±sigma 测量情景；同根所有窗口一致改变，并重新生成 B 和约束，不能一边扰动数据一边保留原基准。
6. 留一独立日重算，检查是否完全由单日决定；只有一日时明确没有此项稳定性证据。

前三项使用预先固定的组合清单，至少包含逐项变化和“更大余量/更强 HR”与“零余量/无 HR”的联合端点。清单及 hash 在验证前冻结，不根据目标 4′00″选情景。所有场景都对各自输入遵守成绩约束。

**不能只取各情景的最优中心极值来表示余量范围。** 单条普通 60 分钟训练的余量先验均值为零时，放大先验尺度并不会移动最优中心，但更快能力仍可能合理。基准情景另作目标剖面：在 log(v60) 上按 0.002 网格固定 a，对其余参数重新最优化，保留 `L_profile(a)<=L_min+2` 且满足约束的集合，边界细化到 log 速度 0.0001。将该集合与所有有效情景中心取并集的包络作为配速敏感性范围。`Delta L=2` 是固定的研究尺度，不赋予概率意义。若可接受集合触及数值域边界，该侧设为未识别，不能把搜索上限当成真实能力上限。

HR 不能只拿逐 a 的单个最优 HR 当作全部范围。归一化分支对 H60 另作 1 bpm 网格的受约束目标剖面、边界细化到 0.1 bpm，重新求 a/k/其余 HR 参数，采用相同 `Delta L=2`，并与 HR 情景中心合并。HR 先验独占分支和 6.4 的回归分支只提供明确的先验/回归情景范围，不冒称联合剖面范围。

没有近全力支持时，数据没有识别出全力速度的快侧上界。即使惩罚剖面给出有限端点，也必须标记 `fast_side=prior_limited`；很多未知努力训练造成剖面变窄，仍可能只是反复施加努力先验，不能升级为数据已识别上界或 high 支持。只有约束且无位置损失时，向上的剖面可能完全平坦，允许快侧无界、中心仍保留有效估计。

报告两个不同对象：**原输入下的名义已证明下界**与**考虑测量/模型变化的敏感性范围**。测量扰动或删去支撑日后范围可能比名义下界更慢；这不是主中心获准违反原始下界。配速范围按速度端点反向转换：`fast=1000/v_high`、`slow=1000/v_low`。

若某些情景求解失败或触及边界，报告失败比例与未识别方向；不能丢掉失败情景后给出看似紧致的完整双侧范围。

### 8.3 输出状态与恢复

- `model_estimated`：存在个人数据参与，但不代表已通过准确性验收。
- `prior_dominated`：仅靠短时/低质量/单层信息，或上述 k/努力/HR 先验情景使配速中心变化超过 3%、HR 超过 5 bpm。判据是首轮解释规则，不是概率。
- `stale`：无新鲜支持，保留历史日期和来源。
- `unavailable`：无合法输入或没有可用退化估计；原因不能只是“无全力测试”。

联合求解失败时，保留配速单独的受约束有效解，HR 走 6.4 的可用路径，报告 `joint_solver_failed`，不伪称联合成功。配速求解也失败时，可输出 `exp(A_floor(0.06))` 作为 `bound_fallback`，前提是有限、未触边且满足全部该 k 的约束；不能只回填一个低于其他 bucket 约束的 B。没有可行下界时才保留明确失败。任何回退均记录方法、输入和原因，不能静默借 v3 的 high 置信度。

主估计的敏感性范围必须包含主中心。若数值边界让可信约束不可行，保留原始成绩和冲突诊断，停止该中心发布；不能通过删掉最快记录让优化器成功。

## 9. 完整计算顺序与输出契约

1. 固定用户、上海 as-of、资料可得截止、输入修订和参数版本；只读加载原始资料。
2. 运行冻结 V3 与 segments-only 对照；清洗、去重并建立新候选池。
3. 按质量、条件、时效分配证据角色，生成 B_eligible 和各时长约束。
4. 先求配速单独解，再按输入能力求 HR 联合解或退化 HR 解。
5. 逐 bucket 检查主解是否覆盖可信表现；检查 V4 与各 V3 对照的差异原因。
6. 运行固定敏感性情景，生成范围、先验影响和失败说明。
7. 输出值、状态、来源与诊断；发布/重算由独立的版本策略处理。

最少诊断字段：

| 类别 | 内容 |
| --- | --- |
| 身份 | algorithm_version=4、algorithm_revision、parameter_version、input_hash、as_of、available_at 语义 |
| 对照 | B_raw、B_repaired、B_eligible、各自实际证据和变慢原因 |
| 结果 | v60、p60、H60、速度/心率范围、范围类型、k、各指标独立状态 |
| 下界 | 每个 bucket 的实际时长/速度/活动日、是否 binding、nominal/model-projected 区分、constraint_violation |
| 贡献 | 配速单独解、联合解、HR 增量、来源日/根计数、努力类别与先验身份 |
| 局限 | prior_dominated、过期/条件冲突、边界、失败情景、回退原因 |

不要把 `v4-v3` 简单称为训练进步：其中包含测量修复、候选范围变化和算法变化。只有同一算法修订、可比输入条件下的时间变化才用于能力趋势解释。

计算 owner 仍是 `src/go/internal/compute/calibration/`；storage 负责一致 snapshot/zones/lineage；客户端消费同一 bundle，不自行重复估计。

本文不改变 [ADR 0045](../adr/0045-calibration-policy-bundles-and-lineage.md) 的只读 GET、原子 bundle、候选隔离及显式发布规则。需要后续显式演进的契约包括：该 ADR/客户端当前“有候选空中心不补 v3”的读取语义继续保留，但**算法内部**现在可以有带来源的 B_eligible/边界回退；旧 source 中“证据日必须是 maximal anchor 日”的定义要改为实际贡献证据日；HR target_type 要新增模型稳态语义。不能只换数值而沿用旧 full-effort/lab 来源标签。

同一 V4 身份的新修订必须可区分并保留历史。现有 `(user,day,version)` 同日覆盖能力本身不提供修订历史，正式落库前需补修订留存/可复现方案；本设计文档不假定这项能力已经实现。

## 10. 供用户进行的验证

以下是验证要求，不是本次已经运行或通过的测试。先固定参数与情景清单，再看结果；所有模型使用相同原始输入、as-of 和可得时间规则。

### 10.1 建议分层比较

| 对照 | 要回答的问题 |
| --- | --- |
| A：冻结 V3 | 原始结果与来源是什么 |
| B：既有 segments-only | 单纯修复测量改变了多少 |
| C：本文约束＋零余量＋无 HR | 成绩保护、近期选择与时长模型本身带来什么 |
| D：C＋努力余量先验 | 提升多少，是否主要由标签与先验制造 |
| E：D＋HR 联合估计 | HR 是否提供额外准确性，还是引入偏差 |

C/D/E 都输出 B_eligible，防止把候选选择变化误算成余量模型的收益。零余量情景将所有 mu 置零，保留相同尺度与硬约束。

### 10.2 必须满足的行为

| 场景 | 预期 |
| --- | --- |
| 可信近期连续 60 分钟 4′11″ | 主中心不得慢于 4′11″；有余量证据可更快 |
| 同条件可信连续两小时 4′11″ | 直接小时下界成立；时长模型可进一步提升，来源区分清楚 |
| 只有 3/5/10 分钟快段 | 能给低支持模型估计，但不能把短段速度直接当小时下界 |
| 普通训练充足，无全力标签 | 不因标签缺失返回空配速；HR 按实际数据/先验路径处理 |
| 加入大量明显慢且不入选的轻松跑，无新增有效 HR | 不稀释原配速拟合，也不制造能力下降 |
| 加入同一活动副本或重复重算 | 中心、范围与独立支持计数不变 |
| 恢复段、停表、GPS 尖峰 | 不产生虚快连续成绩；有可定位的质量说明 |
| 一次低光电 HR vs 多日可靠同配速 HR 改善 | 前者不应大幅抬高能力；后者可影响余量，且影响能在禁用 HR 后消失 |
| 原 V3 结果来自错误或过期记录 | 可以更慢，但每一步有具体来源解释；不得借此绕过仍有效的表现下界 |
| 没有新增证据，只跨过有效期 | 标明过期/历史，不能声称出现了新的能力观测 |
| 真全力参考与当前包络明显矛盾 | 显示冲突及其来源，不默默改变标签或抹掉一边 |

### 10.3 4′11″与约 4′00″的示例

这是代数说明，**不是本用户重算结果**：若同等条件下真的完成了连续两小时、平均 251 秒/km，取 `k=0.06`，则模型小时配速为：

$$p_{60}=251\,(3600/7200)^{0.06}\approx241\;\text{秒/km}.$$

即约 4′01″。它说明无需手工指定 4′00″，长时已完成表现本身就可以通过时长模型提供提升依据；但该换算仍依赖 k、连续性与条件。只有“我觉得能跑两小时”的陈述时，不得套用这个结果。

### 10.4 反馈格式与准确性评价

希望每轮反馈至少包含：

- 数据截止日、输入 hash、算法/参数修订、活动数/独立日、剔除与过期计数。
- A–E 的配速与 HR、B_eligible、范围、状态、求解/情景失败数。
- 每个 bucket 的最佳速度、实际持续时间、日期和约束残差；所有下界违反必须为零。
- 哪些活动决定中心，HR/余量各贡献多少，去掉最关键一日后如何变化。
- 若有独立参考，报告有符号偏差、绝对误差、中位数/P90、覆盖率；按用户、时长、努力标签和传感器分层。
- 没有独立参考时，只能评价一致性、覆盖和敏感性，不能据此宣称“更准”。

新评估使用独立协议 v2；已经用于设计和调参的个人案例、旧最终留出只能作为已知回归案例。全力小时参考、固定距离比赛换算、现场 HR 代理和实验室 LTHR 分开评分。不得为了让新模型胜出修改旧标签或把预测 H60 当成独立真值。

## 11. 尚待验证的主要假设

1. `[0.02,0.10]` 的单段幂律能否覆盖短时优势明显、耐力较弱等用户；若不行，先调整曲线族，不能让模型否认真实成绩。
2. B_eligible 作为兼容下界会不会保留 V3 外推过快的偏差；冲突必须公开，不能用“更快”替代准确性比较。
3. 努力类别余量先验是否带来稳定增益；如果收益主要来自任意百分比，应收回到零余量＋范围。
4. HR 的 q60、beta、日效应与能力是否可区分；若 HR 消融没有稳定改善，保留 HR 输出模型，取消其对配速的反馈。
5. 60 天窗口、前沿 top-3 和近期权重能否兼顾进步响应与历史能力过期；首轮不假定已解决下降检测。

这些问题留待用户验证结果后讨论，不在本文中预先宣称通过。

## 12. 方法依据与适用边界

- [Smyth & Muniz：从原始训练数据计算临界速度](https://researchprofiles.herts.ac.uk/en/publications/calculation-of-critical-speed-from-raw-training-data-in-recreatio/) 支持利用日常训练中的最好表现建模；研究目标是 CS 及马拉松表现，不能直接证明本文的 v60 估计正确。
- [Hunt 等：跑步心率动态辨识](https://pmc.ncbi.nlm.nih.gov/articles/PMC4687158/) 支持在模型中考虑心率滞后及个体差异；该研究的中等至较高强度条件不能直接验证全力一小时 HR、本文的 sigmoid 曲线或参数。
- [Nuuttila 等：固定强度锚点估计乳酸阈值的准确性](https://researchportal.tuni.fi/en/publications/the-accuracy-of-fixed-intensity-anchors-to-estimate-lactate-thres/) 说明群体比例存在个人误差，估计最大值还会引入误差；因此本文 q60 仅为可撤回、需做敏感性分析的研究先验。

本文的硬约束、兼容基准、先验组合和参数初值是针对本产品提出的设计，不是上述论文已经验证过的现成算法。
