## 0. 执行摘要

**STRIDE 是什么**：一个记得住你身体状态、训练历史、目标赛事的**对话式跑步教练**，覆盖跑者**从入坑到 PB（或从久坐到可持续健康跑）**的完整生命周期。不是又一个记录 App，而是把"个体数据 + 训练科学 + AI"咬合成**规划 → 执行 → 跟踪 → 调整**的全程伴跑闭环。

| 维度 | 要点 |
|---|---|
| **问题** | 中国 **1.63 亿**跑步人群绝大多数凭感觉训练：手表数据用不起来、专业教练贵且受地域限制、伤病高发 |
| **时机** | 跑步热（2025 年马拉松参赛 **454 万人次，+9.1%**）× 穿戴渗透（赛事跑者 **84%** 用设备）× AI 临界点（Runna 被 Strava 收购验证品类，但**不进中国**） |
| **方案** | 对话即入口 + 生理信号驱动的周期化执行闭环 + 多设备数据归一化（COROS/Garmin/Apple 专业运动手表）+ 中文训练学/运动医学知识库 |
| **商业模式** | **双引擎**：订阅（Pro ¥29/月）+ 导购分成（装备/赛事/酒店 CPS）—— 免费用户也能变现 |
| **市场** | TAM **4000 亿+** 跑步消费池；SAM **1500–3000 万**有表、有训练意图、有付费力的跑者；SOM（3 年）**15–90 万**付费用户 → 订阅 ARR **0.4–2.5 亿元** |
| **单位经济**（假设） | LTV ~¥215 / CAC ~¥130，**回本周期 ~16 个月**（超 12 月健康线——¥29 低价换转化，需更高 Free→Pro 转化与更低 churn 验证）；LTV/CAC ~1.7，三大杠杆推向 ≥3 |
| **进展** | 教练对话、训练计划、比赛策略已在生产运行；COROS/Garmin/Apple 数据同步已接入；iOS 原生 App + 微信小程序双端就绪（详见 §4.5） |
| **团队** | 互补双创始人：**赵超毅**（产品与技术：IBM 研究院/树根互联研发总监/微软，全栈自研已上线）×**蒋振华**（市场与变现：胜道体育 YYSPORTS 总监）；**两位均为资深跑者（全马 PB 2:57 / 2:56）**，详见 §10 |
| **融资** | 本轮 **300 万元**（轮次/估值待补充）—— 用户增长与市场开拓 50%、产品与算法研发 35%、数据与基础设施 15%（见 §11） |

## 1. 为什么是现在（Why Now）

三股浪潮在 2025–2026 交汇，窗口期正在打开：

1. **跑步成为大众生活方式**：中国跑步人口 1.63 亿；2025 年全国马拉松赛事 594 场、参赛 454.09 万人次（较 2024 年同口径 +9.1%），田协认证赛事完赛 260 万人次、**38.5 万人刷新 PB**——去重后数百万级有明确成绩目标的严肃跑者；全马 A 类赛事直接经济影响 185 亿元（+16.8%），跑者年均跑步消费 ¥3361.8、七成月入过万、六成本科以上——**人群大、在增长、有付费力**。且马拉松平均参赛半径达 516 公里，跨城参赛常态化——比赛周酒店/旅行（R4）有真实的高客单场景。
2. **穿戴设备完成数据基建**：马拉松赛事 84% 跑者使用穿戴设备；中国智能手表年出货 >3500 万部。心率、HRV、配速、负荷等数据已被采集，手表厂商也提供了训练负荷、VO2max 等各类分析——但它们面向泛运动大众市场，**不做路跑备赛（5K/10K/半马/全马）的专业周期化指导**：不排赛季、不追踪执行、不随身体状态逐日调整。数据到「备赛决策」的最后一公里是空的。
3. **AI 能力到达临界点**：大模型 + 个体数据首次让"专业教练级指导"的边际成本趋零。全球品类已被验证——Runna 2025 年被 Strava 收购（App Store 4.9★/~3.1 万评分、180+ 国家），但 **Runna 不进中国**：无中文、无本土支付、母公司 Strava 大陆受限。**中国大陆的 AI 教练品类刚起步：Sigma、RQ、PaceMate 等各有切入但均未确立——格局未定，卡位窗口仍在。**

## 2. 问题：1.63 亿跑者的共同困境

- **凭感觉训练**：不懂周期化与负荷管理，容易过度训练受伤，或长期原地踏步。
- **数据用不起来**：手表采集了心率、配速、负荷、HRV 并提供各类分析指标，但"这周怎么排、备赛周期怎么走、今天该练什么强度"仍全凭感觉——**分析指标无法变成备赛训练决策**。
- **专业指导难获得**：线下私教/跑团贵，且受通勤、时间、地域限制——所在城市未必有合适水平的教练；线上训练营是群发计划，跟不上个体每日状态。
- **需求是整体的**：训练之外还要操心营养、恢复、伤病、选赛、装备——没有一个连贯入口。

这对两类跑者同时成立：① 有明确成绩目标的**备赛跑者**（冲 PB/完赛）；② 只想科学健康跑步的**健康跑用户**。两者都需要"科学、个性化、可负担、随时随地"的指导——**这是当下大众未被满足的需求**。

## 3. 解决方案：对话式 AI 跑步教练

**一句话定位**：一个记得住你身体状态、训练历史、目标赛事的对话式跑步教练，覆盖跑者完整生命周期。

**垂直深耕路跑**：聚焦 5K / 10K / 半马 / 全马等路跑赛事的备赛周期。手表厂商与泛运动平台服务大众记录与分析，不会为单一运动做深专业备赛指导——这是 STRIDE 的立足点，也是与所有泛玩家的分界线。

### 3.1 核心交互：对话即入口

用户在**一个对话框**里说任意诉求——建计划、调计划、问状态、挪课、伤病、装备、选比赛、订酒店——系统识别意图路由到对应能力。一条**滚动会话**贯穿"选比赛 → 定赛事 → 排计划 → taper → 赛后复盘"的连续旅程。

| 模式 | 谁发起 | 例子 |
|---|---|---|
| 被动响应 | 用户提问 | "我状态怎么样？""把明天强度课挪到今天" |
| **主动教练（push）** | 系统主动 | "HRV 连续走低，建议今天降强度""杭马报名明天截止""竞速鞋已跑 600K，该换了" |

**主动教练是留存与差异化的核心**——真教练会主动提醒、预警、督促，而不是干等用户来问。

### 3.2 产品不变量（信任根基）

1. **写操作先提案、后确认**——绝不自动改动用户计划；
2. **安全敏感意图绝不自动改计划**——伤病、不适只给建议；
3. **专业可信**——训练与伤病建议基于自建训练学/运动医学知识库，不靠模型臆断；
4. **外部信息不编造**——赛事、装备、酒店必须有真实数据源；
5. **导购透明**——推荐基于个体适配而非竞价排序，商业推荐与中立建议明确区分。

### 3.3 交付形态

**App + Web 双端，App 优先**：App 是主战场（日常陪伴、主动推送、轻量对话）；Web 面向资深用户（深度分析、计划全景编辑、大屏复盘）。

## 4. 产品全景

### 4.1 十一个能力域

| # | 能力域 | 用户任务 | 变现 | 状态 |
|---|---|---|---|---|
| 0 | **训练计划** | 建赛季/调周/挪课/改目标 | 订阅核心付费墙 | ✅ 已有 |
| 1 | **执行 & 数据洞察** | 今天怎么跑、为何跑崩、瓶颈诊断 | 订阅 | 部分 |

### 4.2 战略分层：订阅命脉 vs 导购薄壳

> **第一原则：订阅护城河 = 训练服务的完整性。** 跑者的训练需求是一个整体——练什么、怎么恢复、吃什么、伤了怎么办。只服务一半，跑者就会流失。

- 🟢 **核心命脉（订阅引擎）**：计划、洞察、健康、营养、恢复、比赛策略、环境改课、知识——服务**全部训练需求**，完整性本身即留存护城河；
- 🟡 **外部世界（导购引擎）**：装备、比赛发现、酒店——接外部真实数据，用个体语境精准推荐，按成交抽成，**免费用户同样变现**；
- ⚪ **社区（引流）**：拉新与留存，后续品牌/广告。

两引擎共享同一资产——**个体数据**：数据越多，订阅内容越专业、导购推荐越精准，互为飞轮。

### 4.3 跑者生命周期（每一步都有变现点）

入坑新手（入门装备导购）→ 进阶系统训练（**订阅转化**）→ 定目标选赛（报名导流）→ 赛季备战（订阅 + 补给装备）→ 比赛周（酒店/竞速鞋高客单）→ 赛后（恢复品 + 续费）→ 淡季维持（留存防流失）。

连续旅程示例：`选比赛(导流) → 定杭马 → 订酒店(OTA) → 排备战计划(订阅) → 买竞速鞋(导购) → taper(订阅) → 赛后复盘(订阅)`

### 4.4 护城河：四层咬合的数据飞轮

**真正的护城河不是数据本身**（手表厂商也有数据、也有分析），**也不是单个公式**（PMC/VDOT/LTHR 都是公开运动生理学）。可防御的是四层长期咬合：

1. **① 多设备数据归一化工程基线**（对标 RQ 的工程标杆）——异构原始数据清洗、对齐、归一是一切分析的地基；当前重点覆盖 **COROS / Garmin / Apple**——严肃跑者的主力专业运动手表生态，与核心付费人群（备赛跑者）高度重合；
2. **② 大规模真实数据校准的算法精度**——个体基线（最大心率/LTHR/阈值配速/区间）、负荷模型（CTL·ATL·TSB）、能力快照与瓶颈诊断，准确度取决于校准数据量与工程打磨，越多真实跑者越准、越难被追平；
3. **③ 周期化执行闭环**——base/build/peak/taper 阶段化计划 + 每周对照实际负荷/疲劳/反馈动态调整，`规划 → 执行 → 跟踪 → 调整` 越用越贴合个体；Sigma 计划已开放但专业性不足（资深跑者视其为数据复述）、RQ 计划是静态模板且无执行追踪——**这正是直接竞品都还浅的一段**；
4. **④ 中文训练学/运动医学知识库**——让伤病、营养、恢复敢答且可信，长期积累、难以速成。

**飞轮**：更多用户 → 更多数据 → 算法与推荐更准 → 留存更高 + 口碑扩散 → 更多用户。同样一句"推荐跑鞋"，普通导购按销量排，STRIDE 按你的步频、落地、周期阶段、周跑量、伤病史推荐——**更可能转化、客单价更高**。

### 4.5 当前进展（截至 2026-10）

## 5. 市场规模（TAM / SAM / SOM）

| 层 | 口径 | 人群/规模 | 年化营收空间（假设）|
|---|---|---|---|
| **TAM** | 全体中国跑步人群 × 跑步年消费 | **1.63 亿**人；跑步产业池 **>4000 亿元/年**（人均 ~¥3362）| 订阅 + 导购理论可触达 4000 亿+ 消费池 |
| **SAM** | 有手表/数据 + 系统训练或备赛意图 + 付费力 | **~1500–3000 万人**（跑步人群 10–18%）| 纯订阅天花板 **~52–104 亿元/年**（Pro ¥348/年）；导购另计 |
| **SOM**（3 年）| SAM 中现实可获取的付费用户 | **~15–90 万**付费用户（渗透 1–3%）| 订阅 ARR **~0.4–2.5 亿元/年**（折后有效 ¥278/年）+ 导购分成 |

**SAM 收窄逻辑**（三条件交集）：① 有手表可同步（赛事 84% 穿戴渗透、年出货 >3500 万）；② 有系统训练/备赛意图（2025 年马拉松参赛 454 万人次、认证赛事完赛 260 万人次，去重后数百万严肃跑者）；③ 有付费力（七成月入过万）。

**SOM 情景**：Base case ≈ 30 万付费用户 → 订阅 ARR ~0.8 亿元 + 导购；Bull case ≈ 90 万 → ~2.5 亿元 + 导购。

> **来源**：赛事数据（594 场/454.09 万人次/+9.1%/完赛 260.27 万/PB 38.5 万/经济影响 185 亿/参赛半径 516 公里）——中国田径协会《2025 中国马拉松赛事蓝皮书》（2026-04）及公开转载；跑步人口 1.63 亿、人均消费 ¥3361.8、收入/学历结构——《2024 年中国路跑工作报告》（2025-03）；穿戴渗透为公开行业报告（2025）。**人群交集、渗透率、ARPU 为本文假设，需早期实测校准。**

## 6. 竞争分析

### 6.1 格局总览

| 类别 | 代表 | STRIDE 的差异 |
|---|---|---|
| **华语 AI·数据跑步（直接竞品）** | **Sigma**（上海）/ **RQ 跑力**（台北）/ **PaceMate**（北京）| 争夺同一批中国跑者的直接竞品；分别偏**记录审美**、**数据分析**与**对话式教练**，**周期化执行闭环均未验证** |
| AI 跑步教练（全球标杆·间接） | **Runna**（2025 被 Strava 收购）| 形态最强参考但不进中国；核心短板：**不吃生理信号、无双向对话、伤病口碑差** |
| 综合运动社交 | Strava / 咕咚 / 悦跑圈 / Keep | 触达大但无严谨 AI 周期化教练；STRIDE 用数据深度切高客单跑者 |
| 西方专业训练 | TrainingPeaks / Final Surge | 弱在中国本地化 + 对话低门槛，非 AI 原生 |
| 手表自带 | Garmin Connect / COROS | 有数据分析与免费训练模板，但面向泛运动大众、**无专业周期化备赛指导**、不对话、锁定单一生态 |
| 真人教练（线下） | 跑团/私教 | 个性化够但**可达性差**（通勤/时间/本地供给）|
| 线上训练营 | 微信训练营 | 可达但**群发计划、个性化不足** |

### 6.2 直接竞品深拆

**PaceMate**（北京动健科技）——国内**形态与 STRIDE 最接近**的直接竞品：对话式 AI 跑步教练（自然语言调计划、问备赛、反馈身体状态），面向 10K–全马备赛人群；训练同步手表跟练、跑步数据自动同步分析、拍照识别营养、跑者力量训练联动；设备覆盖广（Apple Watch / 高驰 / 佳明 / 松拓 / 博能 / 华为）；订阅月卡 ¥39、半年卡 ¥199、年卡 ¥349。

- **市场/体量**：极早期——App Store 中国区评分 5.0 但样本仅个位数；无公开融资信息；抖音有创始人内容营销，用户口碑"对初级跑者或许有用"褒贬不一；版本迭代活跃（周更级）。
- **面向群体**：10K 到全马的备赛跑者——与 STRIDE 核心人群高度重合。
- **STRIDE 的机会**：PaceMate 验证了「对话式备赛教练」的中文需求与 ¥350/年价位带（与 STRIDE ¥348/年几乎一致）；但其训练科学深度与执行闭环尚无实证——个体基线校准、PMC 负荷模型、周期化执行追踪（规划→执行→跟踪→调整）的打磨，加上运动医学知识库与导购变现双引擎，是 STRIDE 的纵深。同形态赛道的胜负手是**训练科学的可信度：谁能让严肃跑者真正进步，谁赢口碑**。

**Sigma**（"你的 AI 跑步记录"）：设计师团队打造，记录 + 分析 + 轻 AI 伙伴先行，审美与仪式感驱动，面向泛跑步人群；训练计划**已开放但专业性不足**——资深跑者反馈其 AI 建议近乎把手表数据换种说法复述一遍，缺乏真正的训练科学增量；知识库偏通识科普。设备覆盖广（苹果/佳明/高驰/华为/小米等），与 STRIDE 重点覆盖的专业表生态重合。**STRIDE 的纵深：以训练系统为核心**——个体负荷模型 + 已落地的周期化执行闭环 + 力量训练集成 + 伤病应答接运动医学 + 导购变现。不靠"也是中文"取胜，靠**训练科学的深度与闭环**拉开差距。

**RQ（跑力）**：华语圈训练科学最严谨的**数据分析**产品（VDOT 跑力、类 PMC 压力指数、体能/疲劳/状态）；但**止步于分析层**——训练计划是 VDOT 套出的静态模板，不随每日状态调整、不追踪执行；繁体界面 / USD 定价，大陆本土化偏弱。**STRIDE 把 RQ 级分析接上对话入口 + 逐日自适应周期化闭环 + 跨品牌多设备覆盖（COROS/Garmin/Apple），从"分析工具"升级为"全程带练的教练"**。

### 6.3 STRIDE 的楔子：「可达性 × 个性化」两个都赢

| | 个性化 | 可达性 |
|---|---|---|
| 线下真人教练 | ✅ 高 | ❌ 差（通勤/时间/本地无同水平教练）|
| 线上训练营 | ❌ 低（群发）| ✅ 高 |
| **STRIDE AI 教练** | ✅ **高**（个体数据 + 周期化闭环，逐日适配）| ✅ **高**（随时随地、不依赖地理）|

**洞察**：大量跑者卡在"想要个性化专业指导，但所在城市没有合适教练"。STRIDE 用 AI 把个体数据驱动的专业指导做到随时随地可达——这是线下教练和群发训练营都占不到的格子。真人教练不被取代，而是**升维到 marketplace（远程、低频、高 touch）**，叠加在 AI 之上面向愿多付费的跑者。

**核心付费人群**：备赛跑者（马拉松/半马）——报名费、装备、旅行都肯花，几十元月费不敏感；**尤其是所在城市缺乏教练资源的进阶跑者**。

## 7. 商业模式：双引擎

### 7.1 模型

```
引擎一：订阅（recurring）—— 变现「完整训练服务」护城河
   规划 + 分析 + 健康/伤病 + 营养 + 恢复 + 改课 + 比赛策略 + 知识 → 月/年费
   留存逻辑：服务越全，跑者越离不开

引擎二：导购分成（transactional）—— 变现「外部世界」
   装备/补给 + 比赛报名 + 酒店旅行 → 按成交 CPS / 导流分成
   免费用户同样变现
```

两引擎共享同一资产：**个体数据**——让订阅内容更专业、让导购推荐更精准。

### 7.2 收入流清单

| # | 收入流 | 类型 | 定价/佣金（假设）|
|---|---|---|---|
| R1 | **个人订阅** | 月/年费 | **¥29/月**；6 月付 9 折、年付 8 折（~¥278/年）；含跑步 + 力量个性化指导 |
| R2 | 装备导购分成 | CPS | 跑鞋/装备联盟 5–15%，高客单竞速鞋 |
| R3 | 比赛报名导流 | 按单/% | 固定 ¥/单 或报名费 % |
| R4 | 酒店/旅行分成 | OTA | 4–10% booking commission；马拉松平均参赛半径 516 公里，跨城参赛常态化 |
| R5 | 品牌合作/测评 | 赞助费 | 新品测评、官方训练伙伴 |
| R6 | 真人教练 marketplace | 平台抽成 | 远程教练撮合，抽 15–30% |
| R7 | 匿名聚合数据洞察 | B2B | 换鞋周期/装备偏好 → 品牌选品（隐私门控）|

**主轴**：R1 订阅（稳定现金流、估值锚）+ R2 导购（高毛利、免费用户可变现）；R5/R7 是规模化后的 B2B 放大器。R2/R5 的落地有联合创始人的运动零售产业资源背书（详见 §10）。

### 7.3 定价三档（假设，待市场验证）

| 档 | 价格 | 解锁 | 人群 |
|---|---|---|---|
| Free | ¥0 | 数据同步、基础状态、有限对话、社区、被导购 | 拉新/新手 |
| **Pro** | **¥29/月**（年付 ~¥278）| 完整教练对话、赛季计划、专业分析、健康伤病、营养恢复、比赛策略 | 进阶/备赛跑者（主力）|
| Elite | ¥99/月（或赛季包）| Pro 全部 + 真人教练对接 + 深度备赛报告 | 严肃备赛/追 PB |

免费档"有用到肯留存"，专业深度留在付费墙后；导购对所有档开放——**免费用户也是变现资产**；付费钩子绑在高意图时刻（建赛季计划、深度诊断、比赛策略）。

**¥29 定价的策略含义**：这是「以价换量」的主动选择——压低付费门槛换取显著更高的 Free→Pro 转化与留存；对单用户收入的缺口，由导购引擎（对所有档变现）与规模后的毛利回升补齐（见 §7.4）。**市场对标**：直接竞品 PaceMate 年卡 ¥349（≈¥29/月）——该价位带已被同类产品采用。

### 7.4 单位经济（假设，待真实投放/留存校准）

**Base case：**

| 指标 | 假设值 | 说明 |
|---|---|---|
| 混合 ARPU | ¥27/月 | 月付 ¥29 与年付折后（¥278/年≈¥23/月）的混合 |
| 月流失率 | 6% | 平均生命周期 ≈ 16 个月 |
| 毛利率 | 30% | 全负载口径（LLM 推理 + infra + 支付 + **分摊研发**，早期研发占比高）|
| 订阅毛利 LTV | ~¥130 | 27 × 16 × 30% |
| 导购增量 LTV | ~¥85 | 人均 GMV ¥800/年 × CPS 8% × 1.3 年 |
| **合计 LTV** | **~¥215** | 订阅 + 导购 |
| 混合 CAC | ~¥130 | 免费获客 ~¥10/人 ÷ 5% 转化 = 纯投放口径 ¥200；**约 1/3 付费用户来自自然流量**（手表导入 + 社区裂变 + 赛事）即可摊到 ¥130，若自然占比达 1/2 则降至 ~¥100 |
| **回本周期** | **~16 个月** | 超出 12 个月健康线——¥29 低价策略需以更高转化与更低 churn 补偿 |
| LTV/CAC | ~1.7 | 未达 3，靠下方三杠杆推向健康区 |

**模型的行为学前提**：跑步是长期行为——跑者以赛季为单位循环训练（每年春秋两个马拉松赛季），跨年复训与参赛是常态。田协蓝皮书数据显示刷新 PB 人数逐年增长（2023 年 20.3 万 → 2024 年 35.6 万 → 2025 年 38.5 万），说明存量跑者不仅留存，还在持续投入。因此订阅流失的主要风险不是"不爱跑了"，而是"赛季结束没人管淡季"——本产品的生命周期覆盖（赛后复盘、淡季维持、主动教练）正是为跨赛季留存而设计；churn 假设建立在这一行为基础上，而非对 App 使用习惯的乐观估计。

**三大杠杆（LTV/CAC 1.7 → ≥3）**：
1. **毛利率随规模回升**——研发是前置固定成本，规模摊薄 + LLM 单位成本走低：毛利 30%→45% 时订阅 LTV ¥130→¥194（最大杠杆）；
2. **压流失**——churn 6%→4% → 生命周期 16→25 月，LTV +56%；主动教练 push 与周期化闭环正是为压 churn 设计；
3. **自然流量压 CAC + 导购净增量**——R2–R4 对免费用户同样变现，是不增获客成本的 LTV 净增量。

**敏感性**：Bear（churn 8% + 毛利 25% + CAC ¥200，即自然流量占比为零的最坏情形）→ LTV/CAC ~0.8 **亏损不可持续**；Base ~1.7；Bull（churn 4% + 毛利 45% + 导购走强）→ ~3.4 健康。**¥29 低价策略成立的前提是转化率与留存同步改善——这连同三杠杆，是必须在早期数据中验证的核心假设；我们按最保守口径规划，不按乐观假设融资。**

## 8. 增长策略（GTM）

### 8.1 破解冷启动：手表数据一键导入

护城河越依赖数据，新用户冷启动越是命门。破法：**onboarding 即同步主流手表历史数据**（COROS / Garmin / Apple 等专业运动手表）+ 用户目标 profile，**Day-1 就兑现价值**——"当前能力评估 + 目标可行性判断 + 首周计划"，无需漫长积累期。多设备覆盖既是获客最低门槛入口，也扩大可触达人群。

### 8.2 获客渠道

| 渠道 | 打法 | 人群 |
|---|---|---|
| 手表用户导入 | 一键同步即见价值（最低门槛 + 解冷启动）| 有表跑者 |
| 内容/KOL | 小红书/B站/抖音跑步博主测评 + 训练科普，建立专业信任 | 进阶 + 新手 |
| 赛事/跑团合作 | 报名季精准触达 | 备赛跑者 |
| 社区裂变 | PB 庆祝、计划/成绩分享、约跑邀请，老带新 | 全体 |
| 应用商店/SEO | "跑步训练""马拉松计划""配速心率"关键词 | 主动搜索者 |
| 免费增值漏斗 | Free 拉新 → 高意图时刻转 Pro | 全体 |

### 8.3 增长飞轮

更多用户 → 更多数据 → 算法与推荐更准 → 留存更高 + 口碑扩散 → 更多用户。数据飞轮同时强化两条护城河（算法精度 + 知识个性化）与两个变现引擎（订阅留存 + 导购精准）。
