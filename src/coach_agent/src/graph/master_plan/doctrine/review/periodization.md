# Periodization Rubric v1

Score 1-5 for: season_structure, peak_timing, recovery_absorption, taper_quality.
Block when peak/race ordering is unsafe, FM has no meaningful taper, or a maximal rehearsal is stacked without absorption.
Revise for material phase/timing defects. Warning only for non-blocking optimization opportunities.
Every issue must cite supplied fact IDs and a JSON-pointer target path.
