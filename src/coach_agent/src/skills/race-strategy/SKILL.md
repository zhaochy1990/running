# 比赛策略补给口径

## 水分补给（固定口径，不写进策略输出）

1. `fueling_plan` 禁止写单纯的喝水/补水行（如「约 5 km：补水 150 ml」）。
2. 水的补充由客户端固定提示承担：「沿途每个水站都进站补水」——全马后半程约每 2.5 km、半马与全马前半程约每 5 km 一站；赛道 `aid_stations` 有数据时以实际站点为时间锚。
3. 补给品的用法说明里可以带一句需水配合（如「需水送服」「服后补水」），这不算补水提醒。

## 能量胶（普通胶 + 双倍胶）

1. 双倍胶 = 双倍碳水、通常含咖啡因；两种胶的详细规格见补给品规格参考。
2. 总量按目标完赛时长定：约每 30–40 分钟一支。
3. 普通胶铺前半程；双倍胶放后半程与关键段（顶坡/冲刺段前）。
4. `fueling_plan` 每行写明用的是哪种胶。

## 盐丸（颗粒 + 液体）

1. 颗粒盐丸需水送服；液体盐丸好入口，服后同样要补水。
2. 总量按赛程时长与赛期气候定：约每 30–45 分钟一粒，高温高湿适当加密。
3. `fueling_plan` 每行写明用的是哪种盐丸。

## 品牌补给品（同类二选一）

1. 能量饮：赛速饮（康比特）或速耐饮（迈胜），二选一、不叠加双份；剂型与使用方式以规格参考为准（如速耐饮为 40ml 液体、开袋即饮，赛前 0.5–1 小时服用）。
2. 抗酸片：酸轻片（康比特）或酸轻片Pro（迈胜），二选一、不叠加双份。
3. 含咖啡因的补给品（速耐饮、双倍胶等）之间错开时间窗，不在同一时间点叠加咖啡因。
4. 详细规格（成分、剂量、服用时间窗、适宜/不适宜人群）见补给品规格参考。

## 打包清单一致性

1. `fueling_checklist` 按品类汇总打包量：普通胶/双倍胶各几支、盐丸（颗粒或液体）几粒、能量饮几袋、抗酸片几片；每行 note 一句关键用法（如「需水送服」「含咖啡因」）。
2. 各品类数量必须与 `fueling_plan` 相应行的加总一致。

## 规格参考的使用

1. `references/fueling-products.md` 是各补给品的规格台账（碳水/咖啡因/钠含量、冲调比例、剂量），制定补给计划与打包清单时以其为准。
2. 参考中标注「待补充」的字段：按通用马拉松补给惯例执行（碳水约 60–90 g/小时的口径），输出中不得出现「待补充」或规格缺失的说明。
