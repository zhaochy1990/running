# 补给品规格参考（race-strategy）

教练制定补给计划与打包清单时引用的规格台账。标注「待补充」的字段由用户补充；
未补充前按 SKILL.md 的通用口径执行，输出中不得提及「待补充」或规格缺失。

## 能量胶

### 普通胶

- 单支规格：待补充（g/支）
- 碳水：待补充（g/支）
- 咖啡因：不含（待确认）
- 建议用法：待补充
- 适用场景：前半程常规补充，约每 30–40 分钟一支

### 双倍胶

- 单支规格：待补充（g/支）
- 碳水：待补充（g/支，约为普通胶 2 倍）
- 咖啡因：待补充（mg/支，通常含）
- 建议用法：待补充
- 适用场景：后半程与关键段（顶坡/冲刺段前）

## 盐丸

### 颗粒盐丸

- 单粒规格：待补充
- 钠：待补充（mg/粒）
- 其它电解质：待补充
- 建议用法：需水送服；约每 30–45 分钟一粒，高温高湿加密
- 适用场景：常规盐分补充

### 液体盐丸

- 单支规格：待补充
- 钠：待补充（mg/支）
- 其它电解质：待补充
- 建议用法：直接饮用，服后补水
- 适用场景：不方便取水送服时的替代

### 赛速饮（康比特）

- 咖啡因：待补充（mg/份，如含）
