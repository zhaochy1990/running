# 补给品规格参考（race-strategy）

教练制定补给计划与打包清单时引用的规格台账。标注「待补充」的字段由用户补充；
未补充前按 SKILL.md 的通用口径执行，输出中不得提及「待补充」或规格缺失。

## 能量胶

### 普通胶

- 单支规格：待补充（g/支）
- 碳水：待补充（g/支）
- 咖啡因：不含（待确认）
- 建议用法：待补充
- 适用场景：前半程常规补充，约每 30–40 分钟一支

### 双倍胶

- 单支规格：待补充（g/支）
- 碳水：待补充（g/支，约为普通胶 2 倍）
- 咖啡因：待补充（mg/支，通常含）
- 建议用法：待补充
- 适用场景：后半程与关键段（顶坡/冲刺段前）

## 盐丸

### 颗粒盐丸

- 单粒规格：待补充
- 钠：待补充（mg/粒）
- 其它电解质：待补充
- 建议用法：需水送服；约每 30–45 分钟一粒，高温高湿加密
- 适用场景：常规盐分补充

### 液体盐丸

- 单支规格：待补充
- 钠：待补充（mg/支）
- 其它电解质：待补充
- 建议用法：直接饮用，服后补水
- 适用场景：不方便取水送服时的替代

## 能量饮（赛速饮 / 速耐饮，二选一）

### 赛速饮（康比特）

- 剂型：待补充（粉剂冲调 / 液体开袋即饮）
- 净含量：待补充
- 碳水：待补充（g/份）
- 电解质：待补充（钠 mg/份）
- 核心成分：待补充（咖啡因 mg/份，如含）
- 使用方式：待补充（服用时间窗）
- 适宜人群：待补充
- 不适宜人群：待补充
- 适用场景：赛前/赛中能量补给节点

### 速耐饮（迈胜）

- 剂型：液体，开袋即饮（无需冲调）
- 净含量：40 ml/袋
- 核心成分：牛磺酸 445 mg、人参 636 mg、咖啡因 85 mg
- 使用方式：开袋即饮，运动前 0.5–1 小时服用
- 适宜人群：中长跑、越野跑、铁三、自行车、游泳、登山徒步等户外运动人群
- 不适宜人群：婴幼儿、孕妇、哺乳期妇女及 14 周岁以下儿童
- 适用场景：赛前能量激活（含咖啡因，与双倍胶等含咖啡因补给错开时间窗）
