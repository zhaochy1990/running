# Speed / VO2-specific phase

- Goal: improve VO2max, running economy, and race-speed tolerance while preserving aerobic support.
- Quality: short or medium repetitions from roughly 200 m to 1 km, hills, and time trials are phase-appropriate when recovery supports them.
- Rotate repetition length and energy-system emphasis; do not reproduce last week's set with cosmetic changes.
- Full recoveries and controlled mechanics take priority over forced pace. Stop the set when form deteriorates.
- Long run remains predominantly easy and should not carry another large quality block in a 2Q week.
