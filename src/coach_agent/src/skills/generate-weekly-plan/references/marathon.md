# 丹尼尔斯训练法｜马拉松专项期（Quality / Specific Phase）【AI最终精简版】

## 一、阶段核心目标
完成训练能力专项转化，将前期通用耐力、速度基础，转化为马拉松配速（MP）专属耐受能力。重点提升长距离糖原利用率、比赛补给适配性、疲劳态配速稳定性，固化匀速跑神经与肌肉记忆，解决赛后程掉速、体能崩盘问题，适配全马专项竞速需求。

## 二、训练优先级（AI 严格执行排序）
本阶段资源完全向马拉松专项倾斜，优先级固定：MP专项训练 ＞ T阈值维持训练 ＞ I/R微量辅助维持。核心有效刺激：稳态MP跑、MP/HMP递进段落、长时长T巡航间歇、内嵌MP段落的专项长距离。

## 三、强度取舍与降级规则（硬性约束）
1. R极速训练降级：取消所有独立大剂量200m/400m R强度主课。仅保留低负荷放松strides，用于维持跑姿与神经活性，不产生训练负荷。
2. I间歇训练降级：取消独立VO2max质量主课，仅保留极小剂量轻量化维持组，不增量、不提质，仅防止速度退化。
3. T阈值训练降级：由主力突破训练转为兜底维持训练，仅保障MP配速稳定性，不再通过大剂量T训练提升耐力上限。
4. 资源绝对倾斜：所有高强度配额、核心训练时长优先供给MP专项训练，停止所有非必要的速度、阈值增量训练。

## 四、周负荷管控铁律（对齐顶层全局规则）
1. Q/L严格独立计数：内嵌MP段落的长跑归类为L长距离课，仅作长距离负荷，不抵扣、不替代独立Q质量课。
2. 专项期锁定 1Q1L：每周仅允许 1 节独立核心质量课 + 1 次长距离课，为唯一合法负荷配置。
3. 专项期永久禁止 2Q1L：双质量课仅适用于预备期后期。专项期使用2Q会导致中枢疲劳堆积、MP体感失真、赛后程崩盘，严格禁用。
4. 强度间隔约束：高强度训练间隔≥48小时，长跑日后不排布任何质量强度课，保障充分恢复。

## 五、进阶逻辑
渐进式提升长距离内MP配速的持续时长与有效里程，本周MP总负荷始终低于下一阶段目标，稳步进阶不冒进。所有专项长距离必须实战演练比赛补给、补水节奏，固化比赛日适配习惯。

## 六、标准化课型分层（AI 排课核心依据｜强制执行）
### 【A级核心主力训练（计入正式 Q/L 负荷，本阶段唯一增量训练）】
1. MP段落质量课（每周首选独立 Q 主课）
标准课型：4×3km MP分段间歇、6–10km 不间断稳态MP。
训练价值：专项期核心强度课，精准打磨马拉松配速体感、匀速经济性与疲劳态配速控制，固化比赛专属肌肉记忆。

2. MP混合专项长距离（每周固定 L 课）
标准结构：总里程26–32km，前半程 E 轻松跑打底，后半程嵌入持续大段 MP 配速。
训练价值：本阶段最高优先级长距离训练，模拟比赛后程糖原枯竭、身心疲劳场景，提升长距离配速稳定性、糖原耐受与实战补给适配。
规则约束：本长跑归类为 L，不抵扣本周独立 Q 课，严格遵守 1Q1L。

3. T阈值维持课（备选独立 Q 主课）
标准课型：20–30min 连续稳态 T 配速或短块巡航间歇。
训练价值：仅维持乳酸阈值基底，辅助支撑MP配速稳定，不做阈值强度突破、不叠加过量T负荷。当本周不安排MP段落Q课时，可作为替代Q课。

### 【B级微量辅助维持训练（不计Q、无训练增量、仅后置维持）】
4. 轻量化VO2max维持（I）
标准配置：6–8×800m 或 3–4×1200m I配速，小剂量、充分恢复。
定位：纯兜底维持，保留基础摄氧量能力、防止速度退化，无专项负荷增益。
排布规则：只能后置在中长距离 E 跑结尾，禁止单独成Q课。

5. 轻量化速度神经维持（R / Strides）
标准配置：少量400m放松重复或短距离加速跨步。
定位：维持步频、跑姿弹性与神经敏感度，避免长期稳态慢跑造成动作僵硬、速度流失。
排布规则：只能后置在日常短 E 跑结尾，零高强度冲刺、零负荷堆积。

### 【辅助训练强制排布规则】
1. 所有B级I/R辅助训练，必须后置附着在日常E轻松跑末尾，禁止单独成课、禁止占用Q课配额。
2. 场景适配：短E跑后放R/strides，中长E跑后放微量I间歇。
3. 严禁叠加：不得在MP主课、T主课、MP长距离课后追加I/R辅助训练，杜绝双重高强度负荷堆积。
4. 负荷定性：所有后置辅助训练为维持性刺激，无专项增益，不改变1Q1L基础架构。

## 七、阶段硬性禁忌（强制规避）
1. 禁止35km以上无强度超长纯慢跑，优先使用「带精准MP刺激的中长距离」，规避过度训练与慢性疲劳。
2. 禁止私自增加质量课数量、禁止开设独立I/R强度主课，全程聚焦马拉松专项适配。
