# Base / aerobic foundation

- Goal: accumulate repeatable aerobic volume, running durability, technique, and strength.
- Quality: normally 1Q1L. Use steady aerobic progression, controlled hills, or light threshold introduction.
- Short relaxed strides of 10-25 seconds with full recovery are allowed as neuromuscular maintenance; they are not maximal-speed intervals.
- Long run: easy and conversational. Progress duration only when the recent long-run history and weekly anchor support it.
- Milestone bridge: build continuous easy duration, stable heart-rate drift, or strength durability before adding intensity.
