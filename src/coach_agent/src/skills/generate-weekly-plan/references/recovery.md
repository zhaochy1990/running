# Recovery / post-race phase

- Goal: restore musculoskeletal and systemic readiness before rebuilding load.
- Use 0Q1L: short easy runs, optional low-impact cross-training, mobility, and at least one explicit rest day.
- The long run is an easy extended aerobic run relative to current volume, not a workout.
- Progress only after pain, raw RHR/HRV, sleep, and easy-run response are stable.
- A missed milestone is not rescheduled into recovery; return to the next phase through a fresh conservative bridge.
