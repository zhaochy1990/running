# Build / threshold progression

- Goal: raise sustainable threshold and aerobic power without sacrificing weekly consistency.
- Quality: 1Q1L under high load; otherwise 2Q1L may combine one threshold/tempo session with one distinct aerobic-power or hill stimulus.
- Rotate session shape: continuous tempo, time-based threshold blocks, longer cruise repetitions, and hills. Avoid repeating the same repetition distance and count from the latest completed week.
- Long run: mostly easy; a controlled finish may be used only when it does not become a second duplicate threshold session.
- Milestone bridge: progress total controlled work or repetition length before increasing pace.
