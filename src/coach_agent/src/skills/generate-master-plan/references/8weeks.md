# 赛前8周训练计划

缩写：
- Q：表示强度课，间歇，节奏，混氧都属于这一类
- L：长距离，包括有氧长距离，渐加速长距离，末段马配长距离，纯马配长距离等
- MP：在全马训练计划中指目标马拉松配速，在半马训练计划中指目标半马比赛配速
- E：有氧慢跑，轻松跑

典型周结构为2Q1L，即一周内两节强度课一节长距离，强度课不能安排在连续的两天，通常有两种方式
1. 周二Q1，周四Q2，周六L
2. 周三Q1，周五Q2，周日L
两种结构下，每周安排一天休息，通常是长距离的前一天，其它时间使用有氧慢跑填充，单次有氧跑最少60分钟，最多90分钟

下面是两个示例训练计划，前6周为马拉松专项期，最后2周为赛前减量期

## 全马课表示例

1. 赛前8周，2Q1L
    1. 强度课，间歇跑1k*12-14，配速比MP快10-15秒每公里，组间休息2-3分钟
    2. 节奏课，变速跑（2k快+2k慢）*4，2k快采用MP或者比MP快5s/km，2k慢采用自身有氧跑配速
    3. 长距离，30-32km，有氧慢跑即可，心率不要高
2. 赛前7周，2Q1L
    1. 强度课，间歇跑2k*6-7，配速比目标马配快10-15秒每公里，组间休息3分钟
    2. 分段加速跑，有氧跑10km+6km@MP
    3. 长距离，32-35km渐加速跑，前20km有氧跑，后12-15km@MP慢10-20s/km
3. 赛前6周，2Q1L
    1. 强度课，倒金字塔跑，5k+4k+3k+2k+1k，配速5k@MP，4k@MP-5秒/km，3k@MP-10s/km，2k@MP-15s/km，1k@MP-20s/km，5k之后休息5分钟，4k之后休息4分钟，3k之后休息3分钟，2k之后休息3分钟
    2. 变速跑，变速跑（2k快+2k慢）*4，2k快采用MP或者比MP快5s/km，2k慢采用自身有氧跑配速
    3. 长距离，35-38km，有氧跑
4. 赛前5周，2Q1L，这周是调整周，但是调整只是“相对”的，不是大幅度减量休息
    1. 变速跑，（3k快+3k慢+2k快+1k慢）*2，配速3k快@MP-5s，3k慢@E，2k快@MP-10，1k慢@E
    2. 节奏跑，12k@MP
    3. 长距离，22-25km@MP-10s
5. 赛前4周，2Q1L
    1. 节奏+间歇，10k@MP + 1k间歇*（3-5组） + 400m*（2-6组），1k间歇配速为MP-（15～20秒），400m配速自由舒展即可，休息时间10k之后休息3分钟，1k组间休息2-3分钟，400m组间休息60秒
    2. 分段加速跑，有氧跑10km+6km@MP
    3. 马配长距离，30-35km@MP
6. 赛前3周，2Q1L
    1. 长间歇，5km*（3-4）配速比MP快5秒，组间休息时间5-7分钟
    2. 分段加速跑，有氧跑10km+6km@MP
    3. 长距离变速跑，（5k快+1k慢）*6，配速5k@MP，1k@E
7. 赛前2周，2Q1L
    1. 节奏+间歇，10k@MP + 1k间歇*（3-5组） + 400m*（2-6组），1k间歇配速为MP-（15～20秒），400m配速自由舒展即可，休息时间10k之后休息3分钟，1k组间休息2-3分钟，400m组间休息60秒
    2. 节奏跑，10k@MP
    3. 长距离渐加速，20-25km，前15km@有氧跑，后5-10km@目标马配
8. 比赛周，1Q1L
    1. 节奏+间歇，5-8km@MP，+1k间歇*（3-5组），1k间歇比MP快15秒，5-8k之后休息3分钟，1k间歇组间休息2-3分钟
    2. 比赛日，全马@MP

## 半马课表示例

半马课表和全马课表整体思路接近，只是训练量进行了减少，部分训练的强度比全马更大一些

1. 赛前8周，2Q1L
    1. 强度课，间歇跑1k*8-10，配速比MP快15秒每公里，组间休息2-3分钟
    2. 节奏课，变速跑（2k快+2k慢）*3，2k快采用MP或者比MP快5s/km，2k慢采用自身有氧跑配速
    3. 长距离，18-20km，有氧慢跑即可
2. 赛前7周，2Q1L
    1. 强度课，间歇跑2k*5，配速比MP快10-15秒每公里，组间休息3分钟
    2. 分段加速跑，有氧跑6km+6km@MP
    3. 长距离，18km渐加速跑，前10km有氧跑，后8km@MP慢5-10s/km
3. 赛前6周，2Q1L
    1. 强度课，倒金字塔跑，4k+3k+2k+1k，配速4k@MP-5秒/km，3k@MP-10s/km，2k@MP-15s/km，1k@MP-20s/km，4k之后休息4分钟，3k之后休息3分钟，2k之后休息3分钟
    2. 变速跑，变速跑（2k快+2k慢）*3，2k快采用MP或者比MP快5-10s/km，2k慢采用自身有氧跑配速
    3. 长距离，18-20km，有氧跑
4. 赛前5周，2Q1L，这周是调整周，但是调整只是“相对”的，不是大幅度减量休息
    1. 变速跑，（3k快+2k慢+2k快+1k慢）*2，配速3k快@MP-10s，2k慢@E，2k快@MP-（15～20s），1k慢@E
    2. 节奏跑，8k@MP-10s
    3. 节奏跑，15km@MP-10s
5. 赛前4周，2Q1L
    1. 节奏+间歇，8k@MP + 1k间歇*（3-4组） + 400m*（2-4组），1k间歇配速为MP-（15～20秒），400m配速自由舒展即可，休息时间10k之后休息3分钟，1k组间休息2-3分钟，400m组间休息60秒
    2. 分段加速跑，有氧跑8km+4km@MP
    3. 节奏跑，15-18km@MP
6. 赛前3周，2Q1L
    1. 长间歇，5km*3，配速比MP快5秒，组间休息时间5-7分钟
    2. 分段加速跑，有氧跑8km+4km@MP
    3. 长距离变速跑，（4k快+1k慢）*4，配速4k@MP，1k@E
7. 赛前2周，2Q1L
    1. 节奏+间歇，6-8k@MP + 1k间歇*（3-5组） + 400m*（2-4组），1k间歇配速为MP-（15～20秒），400m配速自由舒展即可，休息时间10k之后休息3分钟，1k组间休息2-3分钟，400m组间休息60秒
    2. 节奏跑，10k@比MP快5～10s
    3. 渐加速，15km，前5km@有氧跑，后10km@目标马配
8. 比赛周，1Q1L
    1. 节奏+间歇，5-8km@MP，+1k间歇*（3-5组），1k间歇比MP快15秒，5-8k之后休息3分钟，1k间歇组间休息2-3分钟
    2. 比赛日，半马@MP
