# 生成训练计划

## Step 1: 确认训练目标和赛季目标

首先，我们需要确认用户是否有一个赛季目标，如果没有，我们需要询问用户的训练目标。我们当前支持的训练目标包括：
- 全程马拉松（42.195公里）
- 半程马拉松（21.0975公里）

用户需要告诉我们他的目标比赛的时间和地点，以及他希望达到的目标成绩（完成时间）。


然后，我们需要查询用户的PB数据（个人最好成绩），包括：
- 5kpb(5公里PB)
- 10kpb(10公里PB)
- hmpb(半程马拉松PB)
- fmpb(全程马拉松PB)

然后，我们需要查询用户当前的能力水平，主要包括：
- 最大摄氧量（VO2max）
- 阈值心率
- 阈值配速
- 心率区间
- 配速区间

我们需要综合用户的PB数据和当前能力水平，来评估用户的训练目标是否合理，如果用户的目标设置不合理（尤其是目标成绩设置明显超出用户当前能力水平），我们需要提醒用户，并建议他调整目标成绩。
