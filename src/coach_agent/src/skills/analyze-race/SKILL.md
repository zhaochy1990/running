# 分析用户历史比赛数据

## 可用工具与数据边界

1. 调用 `get_race_history` 获取比赛候选和长距离跑，包含日期、距离、用时、平均配速、平均/最高心率和主观感受。
   数据没有显式比赛标记；长距离跑不一定是正式比赛，必须如实称为“比赛候选”或“长距离跑”。
2. 调用 `get_personal_bests` 获取标准距离（1K、3K、5K、10K、HM、FM）的 PB 与取得日期。
3. 调用 `get_running_calibration` 获取最新的阈值心率、阈值速度、心率区间和配速区间。返回 `null` 时，明确说明校准尚未计算，不能自行估算阈值或区间。
4. 如果需要更多训练背景，可调用 `get_activities_by_date_range` 和 `get_daily_training_load`；它们只能说明赛前或赛后的训练背景，不能替代比赛分段、补给或天气数据。

## 历史分析流程

### 1. 建立历史比赛时间线

1. 先调用 `get_race_history`，默认分析半马及以上；用户明确提及 5K、10K 或需要更完整的历史时，将 `minDistanceKm` 调低到相应距离。
2. 按日期从早到晚排序，保留每场的日期、距离、用时、平均配速、平均/最高心率和 `feel`。
3. 按距离分组：5K、10K、HM、FM 只能和同距离历史比较。距离相近但不相同的记录，仅能作为长距离训练背景。
4. 明确区分“正式比赛”和“比赛候选”：工具没有比赛标记，活动名称、距离和强度也不能单独证明它是正式比赛。
5. `get_personal_bests` 为空不代表没有 PB，只表示系统未计算或未存储。

### 2. 识别 PB 和成绩趋势

对每个有两场及以上记录的标准距离：

1. 找出工具返回的 PB，并说明取得日期和来源。
2. 比较最近一场与此前最近同距离比赛的用时、平均配速和心率变化。
3. 总结趋势时只能使用数据支持的表述：连续改善、基本持平、近期回落、样本不足；不要从一场比赛推导长期趋势。
4. PB 很早取得时，不能用它直接代表当前能力；最近同距离比赛优先反映当前表现。
5. 对每场候选记录，保留 `feel`：`excellent`、`good`、`normal`、`bad`、`awful`；`null` 仅表示未填写。

### 3. 判断每场比赛跑得好不好

先为比赛匹配同距离 PB 和目标成绩：

1. PB 只能使用 `get_personal_bests` 返回的同距离记录。
2. 目标成绩只能来自当前或历史训练计划、或用户明确提供的目标；没有目标成绩时，明确写“未记录该场比赛目标成绩”。
3. 比赛候选距离不能可靠匹配标准距离时，不能用 PB 或目标成绩给出“跑得好/不好”的结论，只能描述成绩本身。
4. 用时差 = 本场用时 - 对照用时；相对差 = 用时差 / 对照用时。用时越小越好。

按以下优先级给出比赛质量结论：

| 条件 | 结论 | 要求的表述 |
|---|---|---|
| 本场用时小于同距离 PB | 刷新 PB，跑得好 | 说明刷新秒数和百分比。 |
| 本场用时不慢于 PB 的 1% | 接近 PB，跑得好 | 说明距 PB 的秒数和百分比。 |
| 有目标成绩且本场用时不慢于目标的 1% | 达到或接近目标，跑得好 | 说明相对目标的秒数和百分比。 |
| 相对 PB 或目标慢 1% 至 5% | 未达最佳，但表现可接受 | 说明落差；不能据此断言跑崩。 |
| 相对 PB 或目标慢超过 5% | 明显未达预期，跑得不好 | 说明对照是 PB 还是目标，以及落差。 |
| 没有可用的同距离 PB 或目标 | 无法判定比赛质量 | 不以主观感受、心率或跨距离配速代替成绩对照。 |

同时存在 PB 和目标时，分别报告两种对照；不要用一个结论掩盖另一个。例如，刷新 PB 但未达到更激进的目标，应明确写“刷新 PB，但未达到目标”。

`feel=bad/awful` 是补充信号：即使成绩接近 PB，也可提示主观体验不佳；但它不能推翻实际成绩结论。反之，`feel=good` 也不能抵消明显慢于 PB 或目标的事实。

### 4. 解读强度与能力背景

- 平均心率、最高心率落在最新心率区间的哪一段。阈值或区间缺失时不作强度归类。
- 平均配速相对于最新阈值速度或配速区间的位置。最新校准可能晚于比赛，不能把它当成比赛当天的精确生理阈值。
- 不同距离的心率和配速不能简单横向比较；全马、半马和 10K 的可持续强度不同。

配速字段为秒/公里，展示时转换为 `mm:ss/km`；用时为分钟时，展示为适合距离的时分秒格式。

### 5. 判断历史中的疑似跑崩

只能使用以下可观察信号，结论必须使用“可能”或“未见明显证据”等符合证据强度的措辞：

- `feel=bad` 或 `feel=awful`。
- 同距离成绩显著慢于 PB，且 PB 足够近期或近期同距离候选也明显更快。
- 平均配速显著低于其近期同距离表现，同时主观感受不佳。

以下信息当前工具没有，不能编造：分段配速、后程掉速时间点、补给量、气温湿度、赛道爬升、伤痛类型、抽筋、胃肠反应或睡眠。

不要仅凭“成绩比 PB 慢”断言跑崩：PB 可能陈旧，比赛也可能是训练中的配速跑、健康完赛或主动配速控制。

### 6. 输出结构

按以下顺序简洁回答：

1. **历史概览**：覆盖的日期范围、记录数量、哪些是比赛候选。
2. **比赛质量表**：每场列出距离、用时、PB、目标成绩（若有）、与 PB/目标的秒数和百分比差、结论（刷新 PB / 接近 PB / 达到目标 / 未达最佳 / 明显未达预期 / 无法判定）。
3. **按距离趋势**：每个距离的 PB、最近成绩、与上次同距离的变化，以及趋势结论。
4. **关键比赛复盘**：挑选最能代表进步、回落或疑似跑崩的 1 至 3 场，列出数据依据。
5. **能力背景**：仅在校准数据可用时说明相对阈值和区间的位置，并声明校准日期。
6. **不确定项与计划启示**：明确缺少的目标、分段、补给、天气、赛道和伤病信息；给出与数据相符的训练重点，不把推测写成事实。
